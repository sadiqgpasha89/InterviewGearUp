# Content quality report

Generated by `npm run content:audit -- --write` from the data files. Do not edit by hand; `npm test` fails when it is out of date.

The rubric signals are text heuristics. They point a reviewer at likely gaps (no example, no trade-offs, thin explanation and so on). They cannot judge technical correctness, so they never change a review status; only a person can mark an answer Human-reviewed or Needs correction. See CONTRIBUTING.md for the review workflow.
