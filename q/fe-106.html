Explain the CSS position property: static, relative, absolute, fixed and sticky.

Frontend engineer · Gear 1 (Junior) · CSS · Difficulty: easy · AI-drafted, not yet reviewed by a person

In 30 seconds

static is the default normal flow. relative offsets an element from its normal place while keeping its space and becomes the reference for absolute children. absolute removes the element from the flow and positions it against the nearest positioned ancestor. fixed positions against the viewport, and sticky behaves as relative until a scroll threshold, then sticks.

Explained in depth

The values

ValueBehaviour
staticDefault. Normal flow; top, left and z-index have no effect.
relativeStays in flow (its original space is kept) but can be shifted with top, left, etc. Creates a reference point for absolute children.
absoluteRemoved from flow. Positioned relative to the nearest ancestor that is not static (or the initial containing block).
fixedRemoved from flow and positioned relative to the viewport, so it stays put while scrolling.
stickyActs like relative until it reaches a scroll offset (such as top: 0), then stays fixed inside its scroll container.

Common pattern

.card { position: relative; }
.card .badge { position: absolute; top: 8px; right: 8px; }

The badge sits in the card's corner because the card is the positioned ancestor.

Sticky header

header { position: sticky; top: 0; }

Sticky fails when an ancestor has overflow: hidden or auto (it then sticks within that box), when the parent is too short, or when no top, bottom, left or right is set.

Stacking

z-index only works on positioned elements (and flex or grid items) and is compared inside the same stacking context. A new context is created by position with z-index, opacity below 1, transform, and isolation: isolate. If a high z-index element is still hidden, check whether its ancestor creates a lower context.

Modern advice

Prefer Flexbox or Grid for layout and keep positioning for overlays, badges, tooltips and sticky elements.
