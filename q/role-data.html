Gear 1: Junior (0 to 2 years)

  • What is the difference between OLTP and OLAP? What is a star schema?
  • ETL versus ELT: what is the difference and when do you choose each?
  • What is the difference between a data warehouse and a data lake?
  • How do you remove duplicate rows in SQL while keeping the most recent one?
  • What is the difference between GROUP BY and window functions in SQL?
  • What is the difference between normalization and denormalization, and when is each used in analytics?
  • What are the main stages of a data pipeline, from ingestion to serving?
  • What is the difference between batch and stream processing, and how do you choose?
  • What are structured, semi-structured and unstructured data? Give examples and how each is stored and queried.
  • Compare CSV, JSON and Parquet as data file formats.
  • What are the common dimensions of data quality and how do you check them in a pipeline?
  • What is a CTE in SQL, and when do you use it instead of a subquery?
  • What is Apache Spark, and why use it instead of a single-machine tool such as pandas?
  • How do NULLs behave in SQL comparisons, aggregates and joins, and how do you handle them?
  • Why use a workflow orchestrator such as Airflow instead of cron jobs for data pipelines?

Gear 2: Mid-level (2 to 5 years)

  • Write SQL to find the top 2 earners in each department, and a running total of revenue by month.
  • How do you make a data pipeline idempotent and handle late-arriving data and backfills?
  • Compare Kimball Star Schema and Snowflake Schema in dimensional data warehousing.
  • Explain Slowly Changing Dimensions: Types 1, 2, 3, and 6 with practical examples.
  • What is the difference between Additive, Semi-Additive, and Non-Additive fact tables?
  • When is One Big Table (OBT) preferred over normalized dimensional schemas in modern warehouses?
  • Explain the Apache Spark driver, executor, and cluster manager architecture.
  • Compare Resilient Distributed Datasets (RDD), DataFrames, and Datasets in Apache Spark.
  • Explain the difference between narrow transformations and wide transformations in Spark.
  • Explain Apache Parquet internal layout: Row Groups, Column Chunks, and Pages.
  • Compare Parquet, ORC, and Avro: When should you use row-oriented versus columnar formats?
  • Compare Snappy, Zstandard (Zstd), and Gzip compression algorithms in data engineering.
  • What causes the small files problem in data lakes and what compaction strategies resolve it?
  • How do table partitioning and clustering reduce query byte scanning and costs in BigQuery?
  • How do Materialized Views and automated query rewrite improve dashboard performance?
  • Explain the core concepts of dbt (data build tool): Models, Sources, Seeds, and Snapshots.
  • What is the difference between generic dbt tests and singular custom SQL tests?
  • Explain the Apache Airflow architecture: Webserver, Scheduler, Metadata Database, and Workers.
  • What are the best practices for writing idempotent Airflow DAGs and avoiding top-level code?
  • How does Apache Kafka partition topics, and how do consumer groups parallelize message consumption?
  • What is Kafka Connect and how do Source and Sink connectors simplify pipeline ingestion?
  • How does Great Expectations automate data quality profiling and test validation in CI/CD?
  • Compare ELT and ETL paradigms: Why has ELT become dominant with cloud data warehouses?
  • Explain the Medallion Architecture: Bronze (Raw), Silver (Cleansed), and Gold (Aggregated) layers.
  • How do you safely backfill historical pipeline runs in Apache Airflow without overloading databases?
  • Compare surrogate keys and natural business keys in relational dimensional modeling.
  • What are degenerate dimensions and junk dimensions, and when should you use each?
  • Compare Broadcast Hash Join with Sort Merge Join in distributed SQL engines.
  • How do Delta Lake and Iceberg handle schema evolution when columns are added, renamed, or dropped?
  • How do cloud storage lifecycle rules automatically transition older data from Standard to Coldline/Archive?
  • What is the difference between Airflow TaskGroups and legacy SubDAGs?
  • How do you configure Airflow SLA (Service Level Agreement) callbacks and alerts on delayed pipelines?
  • Explain Kafka producer acknowledgment settings: `acks=0`, `acks=1`, and `acks=all`.
  • How do Kafka log retention policies balance disk space with consumer replay requirements?
  • Compare Tumbling Windows, Sliding Windows, and Session Windows in real-time stream aggregation.
  • How do you efficiently ingest and flatten semi-structured nested JSON arrays into tabular warehouses?
  • How do you generate realistic anonymized test datasets for staging and developer environments?
  • What is Reverse ETL and how does it sync modeled warehouse data back into operational CRMs?

Gear 3: Senior (5 to 8 years)

  • A Spark job is slow because of data skew. How do you diagnose and fix it?
  • Design a clickstream analytics pipeline.
  • How does Data Vault 2.0 structure data into Hubs, Links, and Satellites?
  • Compare Data Lakehouse architecture with traditional Data Warehouses and Data Lakes.
  • Explain Lambda Architecture versus Kappa Architecture for stream and batch processing.
  • How does the Spark Catalyst Optimizer optimize logical plans into physical execution plans?
  • What is the Tungsten execution engine in Spark and how does whole-stage code generation work?
  • What causes data skew in Spark joins and how does key salting resolve partition bottlenecks?
  • How do you tune `spark.sql.shuffle.partitions` to avoid small files and spill-to-disk?
  • Explain Spark memory management: Storage Memory versus Execution Memory and off-heap memory.
  • How does Spark Dynamic Resource Allocation scale executors up and down based on backlog?
  • How does Spark Structured Streaming handle late data using event-time watermarking?
  • What are open table formats (Apache Iceberg, Delta Lake, Apache Hudi) and what problems do they solve?
  • How does Apache Iceberg guarantee ACID transactions and snapshot isolation on cloud object storage?
  • How does Time Travel work in Delta Lake and Iceberg using immutable snapshot manifests?
  • Compare Copy-on-Write (CoW) and Merge-on-Read (MoR) storage strategies in Apache Hudi.
  • What is hidden partitioning in Apache Iceberg and how does it prevent query user errors?
  • Explain Snowflake architecture: Cloud Services layer, Virtual Warehouses, and Storage layer.
  • How do Snowflake micro-partitions and clustering keys prune scanned data during queries?
  • Explain Google Cloud BigQuery architecture: Dremel compute, Capacitor storage, and Colossus.
  • Explain Amazon Redshift distribution styles (KEY, EVEN, ALL) and sort keys (Compound vs Interleaved).
  • How do dbt incremental models work with merge, delete+insert, and append strategies?
  • Compare Airflow executors: CeleryExecutor versus KubernetesExecutor versus LocalExecutor.
  • What is the difference between Airflow standard Sensors and Deferrable (Async) Operators?
  • How does OpenLineage capture and visualize end-to-end data lineage across multi-engine pipelines?
  • How does Confluent Schema Registry enforce Backward, Forward, and Full schema compatibility?
  • Explain Apache Flink time semantics: Event Time versus Processing Time versus Ingestion Time.
  • What are Data Contracts and how do they establish API-like guarantees between producers and consumers?
  • How do you detect statistical anomalies in data distributions using Z-score and Interquartile Range (IQR)?
  • How do you implement PII masking, tokenization, and hashing in compliance with GDPR and HIPAA?
  • How do Role-Based Access Control (RBAC) and row-level/column-level security work in modern warehouses?
  • How do you implement GDPR Right to Be Forgotten deletion requests in append-only Parquet data lakes?
  • What is Change Data Capture (CDC) and how does Debezium stream database changes into Kafka?
  • How do you handle late-arriving dimensions and early-arriving facts in data pipelines?
  • How do federated queries and external tables allow querying data lakes directly from SQL warehouses?
  • What query optimization techniques prevent expensive shuffle operations in BigQuery and Snowflake?
  • What is speculative execution in Apache Spark and how does it mitigate straggler tasks?
  • Why do standard Python UDFs suffer severe performance penalties in PySpark compared to Pandas UDFs?
  • How does partition evolution work in Apache Iceberg without rewriting historical table data?
  • How do Lakehouses resolve write conflicts when multiple pipelines write to the same table concurrently?
  • What is zero-copy cloning in Snowflake and Databricks, and how does metadata pointer copying work?
  • Compare Dagster software-defined assets with Airflow imperative task execution models.
  • What is the dbt Semantic Layer and how does it define consistent business metrics across BI tools?
  • How do you deduplicate incoming streaming events using stateful rocksdb storage in Apache Flink?
  • What are the five pillars of Data Observability: Freshness, Volume, Schema, Quality, and Lineage?
  • How do you automate schema drift detection when upstream API producers alter JSON payloads?
  • How do automated data catalogs (DataHub, Amundsen) index metadata and facilitate data discovery?
  • How do you optimize Snowflake compute spend using auto-suspend, warehouse rightsizing, and scaling policies?
  • Compare BigQuery slot reservations with on-demand pricing for high-volume enterprise workloads.
  • How do you diagnose and resolve Out of Memory (OOM) errors in Spark driver and executor nodes?
  • What causes memory spill to disk in Spark and how do you tune memory fraction allocations?
  • How do vector databases integrate into enterprise data lakehouse pipelines for AI applications?
  • How do Slowly Changing Dimension Type 4 (Historical Min/Max Tables) scale over billions of rows?
  • Design a high-throughput clickstream event ingestion pipeline handling 500,000 events/second.
  • Compare ClickHouse, Apache Pinot, and StarRocks for real-time sub-second analytics dashboards.

Gear 4: Lead / Staff (8+ years)

  • Warehouse or lakehouse? How do you choose, and how do you govern data quality across teams?
  • How does Apache Flink achieve stateful fault tolerance using asynchronous barrier checkpointing?
  • How does a Two-Phase Commit Sink guarantee end-to-end exactly-once processing in stream pipelines?
  • What is Data Mesh and how does domain-driven decentralization shift data ownership to product teams?
  • How do you execute a zero-downtime data warehouse migration between cloud providers?
  • How would you design a data platform that serves both analytics and machine learning for a large company?
  • How would you build a data governance programme that people actually follow?
  • How do you design disaster recovery and multi-region resilience for a cloud data platform?
  • How do you control the cost of a petabyte-scale data platform without hurting users?
  • How do you migrate a batch ETL platform to streaming without disrupting downstream consumers?
  • How do you create a single source of truth for company KPIs and prevent metric definitions from drifting?
  • How do you design a data platform that is privacy-by-design for GDPR and CCPA?
  • How do you build and lead a data engineering team: structure, hiring, on-call and ways of working?
  • How do you define SLAs and SLOs for data products and manage data incidents?
  • How do you decide whether to build or buy components of a data platform, and manage vendor lock-in?
  • How do you design a multi-tenant data platform with isolation, chargeback and fair resource sharing?
