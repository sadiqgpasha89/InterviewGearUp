How does logistic regression work, and why is it used for classification despite the name?

ML / AI engineer · Gear 1 (Junior) · Models · Difficulty: easy · AI-drafted, not yet reviewed by a person

In 30 seconds

Logistic regression computes a weighted sum of the features, passes it through the sigmoid function to get a probability between 0 and 1, and classifies by comparing that probability to a threshold. It is trained by minimising log loss, gives interpretable coefficients, and is a strong baseline for binary classification, with softmax extending it to several classes.

Explained in depth

Model

  1. Compute a linear score: z = w1*x1 + w2*x2 + ... + b.
  2. Apply the sigmoid function: p = 1 / (1 + e^(-z)). This squashes any number into the range 0 to 1, interpreted as the probability that the example belongs to the positive class.
  3. Predict class 1 if p >= threshold (0.5 by default).

The name comes from the logit (log-odds): log(p / (1 - p)) = z, so the model is linear in the log-odds.

Training

  • The loss is binary cross-entropy (log loss): -[y log p + (1-y) log(1-p)], averaged over examples. It heavily penalises confident wrong predictions.
  • It is convex, so gradient descent (or solvers like L-BFGS) finds the global optimum.
  • Add L1 or L2 regularisation to prevent overfitting; in scikit-learn, parameter C is the inverse of regularisation strength.

Interpretation

Each coefficient is the change in log-odds for a one-unit increase in a feature (holding others fixed); exp(w) is the odds ratio. This is why it is popular in medicine, credit and other regulated settings.

Practical points

  • Scale features for faster convergence and fair regularisation.
  • It assumes a linear decision boundary in the feature space; add interactions or polynomial features, or use trees and neural networks for non-linear patterns.
  • For imbalanced data, use class weights, and evaluate with precision, recall and PR-AUC; pick the threshold based on business costs.
  • Probabilities are usually reasonably calibrated, which is useful for ranking and decision making.
  • Multiclass: one-vs-rest or softmax (multinomial) regression.
