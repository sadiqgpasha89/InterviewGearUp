How should you interpret a confidence interval, and how does it differ from a Bayesian credible interval?

Data scientist · Gear 2 (Mid-level) · Statistics · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

A 95 percent confidence interval comes from a procedure that captures the true parameter in 95 percent of repeated samples, so the probability statement is about the procedure, not this one interval. A Bayesian credible interval states directly that the parameter lies within it with 95 percent probability given the prior and data.

Explained in depth

Frequentist confidence intervals

In frequentist statistics the true parameter (for example the real conversion lift) is fixed but unknown, and the data are random. A 95 percent confidence interval is constructed so that, if you repeated the experiment many times, 95 percent of the intervals would contain the true value. For one observed interval, the true value is either inside or not; the 95 percent describes the long-run coverage of the method.

  • Typical formula: estimate +/- critical value x standard error (for a mean, x-bar +/- t x s / sqrt(n)).
  • Width shrinks with larger n (as 1 / sqrt(n)), grows with variance and with confidence level.
  • Useful readings: the interval shows the range of effect sizes consistent with the data. If it excludes zero, the two-sided test rejects zero at the matching alpha. A wide interval signals low precision even if p < 0.05.
  • Many people informally say "95 percent probability the parameter lies here"; that is the credible interval interpretation, not the confidence interval one.

Bayesian credible intervals

Bayesian inference treats the parameter as a random variable with a prior distribution, updates it with the data through Bayes' theorem to get a posterior, and a 95 percent credible interval is a range containing 95 percent of the posterior probability: "given our model, prior and data, there is a 95 percent probability the lift is between 0.1 and 0.6 percentage points". Variants: equal-tailed interval and highest posterior density (HPD) interval.

# Conversion A/B with Beta-Binomial model
import numpy as np
from scipy import stats
a = stats.beta(1 + 520, 1 + 10000 - 520)       # control: 520 conversions of 10000, Beta(1,1) prior
b = stats.beta(1 + 565, 1 + 10000 - 565)
diff = b.rvs(100000) - a.rvs(100000)
print(np.percentile(diff, [2.5, 97.5]), (diff > 0).mean())   # credible interval and P(B > A)

Practical issues

  • Prior choice matters with small samples: do a sensitivity analysis with different priors; weakly informative priors are a sensible default; justify informative ones with historical data.
  • Non-normal or complicated metrics (ratios, medians, percentiles, revenue per user): use the delta method for ratios, bootstrap confidence intervals (percentile or BCa), or model-based intervals. Clustered data needs cluster-robust or hierarchical models.
  • Multiple comparisons affect both; simultaneous intervals or hierarchical models help.
  • Check that model assumptions hold; an interval is only as valid as the model.
  • Report effect size with interval and what it means for the decision, rather than only "significant".

Interview framing

"A confidence interval tells you how well the procedure performs over repeated sampling; a credible interval gives a direct probability statement but depends on the prior. With plenty of data they typically agree, and I report the interval and the decision-relevant probability."

Pitfalls

Interpreting a single 95 percent confidence interval as a 95 percent probability statement, treating overlapping intervals as proof of no difference (they can still differ significantly), and ignoring priors in Bayesian analyses.
