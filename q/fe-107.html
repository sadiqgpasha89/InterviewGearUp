What is responsive design, and how do media queries and a mobile-first approach work?

Frontend engineer · Gear 1 (Junior) · CSS · Difficulty: easy · AI-drafted, not yet reviewed by a person

In 30 seconds

Responsive design makes one codebase adapt to any screen size using fluid layouts, flexible images and media queries. Mobile-first means writing the base styles for small screens and adding min-width media queries as space grows, which keeps CSS simpler and loads less on phones. Set the viewport meta tag and test on real devices.

Explained in depth

Ingredients

  1. Viewport meta tag: <meta name="viewport" content="width=device-width, initial-scale=1">. Without it, phones render a wide virtual page and shrink it.
  2. Fluid layouts: use relative units (%, rem, fr, vw), Flexbox and Grid with auto-fit and minmax(), rather than fixed pixel widths.
  3. Flexible media: img { max-width: 100%; height: auto; }, and srcset and sizes (or <picture>) so the browser downloads an appropriately sized image.
  4. Media queries: apply styles when conditions match.
/* mobile first: base styles are for small screens */
.layout { display: grid; gap: 16px; }

@media (min-width: 768px) {
  .layout { grid-template-columns: 1fr 2fr; }
}
@media (min-width: 1200px) {
  .layout { max-width: 1100px; margin-inline: auto; }
}

Why mobile-first

  • Small-screen layout is usually the simplest (one column), so base CSS stays small, and larger screens add enhancements.
  • Phones do not parse or override large desktop rules.
  • It encourages prioritising content and performance.

Choosing breakpoints

Base them on where your content breaks, not on specific devices. Typical starting points are 600, 768, 1024 and 1280 px.

Beyond viewport width

Container queries (@container) let a component adapt to its own container; clamp() gives fluid typography (font-size: clamp(1rem, 2.5vw, 1.5rem)); prefers-reduced-motion and prefers-color-scheme respond to user settings. Tap targets should be at least about 44 px, and always test on real devices and with zoom.
