How does OAuth 2.0 Authorization Code Flow with PKCE protect against authorization code interception?

Backend engineer · Gear 3 (Senior) · Security · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

In the Authorization Code flow with PKCE, the client creates a random code_verifier, sends its hash (code_challenge) with the authorisation request, and later proves possession by sending the original verifier when exchanging the code for tokens. An attacker who intercepts the authorisation code cannot redeem it without the verifier.

Explained in depth

The threat

Public clients such as mobile and single-page apps cannot keep a client secret. If another app or a malicious script captures the redirect with the authorisation code, it could exchange it for tokens.

PKCE (Proof Key for Code Exchange, RFC 7636)

  1. The client generates a random code_verifier (43 to 128 characters).
  2. It computes code_challenge = BASE64URL(SHA256(code_verifier)).
  3. It sends the user to the authorisation endpoint with response_type=code, the client id, redirect URI, code_challenge, code_challenge_method=S256 and state.
  4. After login the server redirects back with code, and remembers the challenge with that code.
  5. The client calls /token with code and the original code_verifier.
  6. The server hashes the verifier and compares it with the stored challenge. Only the client that started the flow can pass.

An attacker who steals the code does not have the verifier, and cannot derive it from the hash.

Related protections

  • state: a random value tied to the user's session, checked on return, defending against CSRF and mix-up.
  • Exact redirect URI matching, and use of the system browser instead of embedded webviews.
  • Short-lived codes that can be used only once.

Current guidance

OAuth 2.1 and security best practices require PKCE for all clients, including confidential server-side ones, because it also stops code injection. The implicit flow, which returned tokens directly in the URL, is deprecated.
