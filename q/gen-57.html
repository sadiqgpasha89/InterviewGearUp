Compare QuickSort and MergeSort: Stability, in-place memory usage, and worst-case time complexities.

Software engineer (core) · Gear 2 (Mid-level) · Algorithms · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

Both average O(n log n). MergeSort is stable, guarantees O(n log n) in the worst case, and needs O(n) extra space; QuickSort is usually faster in practice and sorts in place with O(log n) stack, but is not stable and degrades to O(n^2) with bad pivots unless randomized or introspective.

QuickSort in brief

Choose a pivot, partition so smaller items are left and larger are right, recurse on both sides. A bad pivot (already sorted input with first element pivot) gives unbalanced splits and O(n^2).

def quicksort(a, lo=0, hi=None):
    hi = len(a) - 1 if hi is None else hi
    while lo < hi:
        p = partition(a, lo, hi)          # randomized or median-of-three pivot
        if p - lo < hi - p:               # recurse on the smaller side,
            quicksort(a, lo, p - 1); lo = p + 1   # loop on the larger: stack O(log n)
        else:
            quicksort(a, p + 1, hi); hi = p - 1

MergeSort in brief

Split in half, sort each half, merge the two sorted halves with a linear scan. Taking from the left run on ties preserves stability.

Choosing between them

  • Need stability (sort by name, then stably by department): MergeSort or Timsort.
  • Linked lists: MergeSort needs no random access and O(1) extra space.
  • Data that does not fit in memory: external merge sort over sorted runs.
  • Primitive arrays in memory: QuickSort variants win through cache locality.
  • Predictable latency: MergeSort or heapsort, because worst case is bounded.

What libraries do

  • Java: dual-pivot QuickSort for primitives, TimSort (a MergeSort hybrid) for objects, to keep stability.
  • Python and Java object sorts: Timsort (runs plus merging, O(n) on already sorted data).
  • C++ std::sort: introsort (QuickSort that switches to heapsort at depth 2 log n, then insertion sort for small ranges); std::stable_sort uses merge sort.

Pitfalls

Using the first element as pivot on sorted input, forgetting many equal keys (use three-way partitioning, Dutch national flag), and assuming sort is stable when the language does not guarantee it.
