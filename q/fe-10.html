What is the difference between Reflow (Layout) and Repaint, and how do you minimize reflows?

Frontend engineer · Gear 2 (Mid-level) · DOM · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

Reflow (layout) recalculates the size and position of elements, while repaint redraws pixels without changing geometry. Reflow is more expensive and always leads to a repaint. Minimise it by batching DOM reads and writes, avoiding layout thrashing, animating transform and opacity instead of layout properties, and keeping the DOM small.

Explained in depth

The rendering pipeline

Style calculation, then layout (reflow), then paint, then composite. Changing a property starts the pipeline at the earliest stage that it affects.

  • Reflow: changing geometry (width, margin, font-size, adding or removing nodes) or reading layout values forces the browser to recompute positions, often for a large part of the tree.
  • Repaint: changing appearance without geometry (color, background, box-shadow) redraws pixels but keeps the layout.
  • Composite only: transform and opacity can be handled on the GPU as separate layers, skipping layout and paint.

Layout thrashing

Alternating writes and reads forces the browser to recalculate layout each time:

for (const el of items) {
  el.style.width = box.offsetWidth + 'px';   // read, then write, then read again...
}

Fix it by reading everything first, then writing:

const w = box.offsetWidth;                    // one read
for (const el of items) el.style.width = w + 'px';   // writes only

Ways to reduce reflow

  • Batch DOM changes with a document fragment, toggle a class instead of many inline styles, and use requestAnimationFrame for visual updates.
  • Animate transform and opacity, not top, left or width.
  • Avoid deep, complex DOM trees and layout-heavy selectors; apply contain: layout paint or content-visibility: auto to isolate off-screen sections.
  • Reserve space for images and ads (width and height or aspect-ratio) to avoid layout shifts.
  • Check the Performance panel for purple (layout) and green (paint) blocks.
