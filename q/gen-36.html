Explain the sliding window pattern: Fixed-size window versus dynamic-size window with two pointers.

Software engineer (core) · Gear 2 (Mid-level) · Algorithms · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

A sliding window keeps a contiguous range of an array or string and moves it forward instead of recomputing. A fixed-size window adds the new element and removes the oldest. A dynamic window expands the right end until a condition holds and shrinks the left end while it stays valid. Each element enters and leaves once, so it is O(N).

Explained in depth

Fixed-size window

Maximum sum of any k consecutive numbers:

def max_sum(nums, k):
    window = sum(nums[:k])
    best = window
    for i in range(k, len(nums)):
        window += nums[i] - nums[i - k]    # add new, drop oldest
        best = max(best, window)
    return best

Dynamic window

Shortest subarray with sum at least target (positive numbers):

def min_len(nums, target):
    left = total = 0
    best = float('inf')
    for right, x in enumerate(nums):
        total += x
        while total >= target:             # shrink while valid
            best = min(best, right - left + 1)
            total -= nums[left]
            left += 1
    return 0 if best == float('inf') else best

When to use it

Look for a contiguous subarray or substring with a condition on its contents (sum, distinct characters, counts) and a window that grows or shrinks monotonically. The while loop inside for is still O(N) because left only moves forward.

Limits

Negative numbers break the shrink logic for sum conditions, because shrinking might not reduce the sum; use prefix sums with a hash map instead. Window maximum needs a monotonic deque.
