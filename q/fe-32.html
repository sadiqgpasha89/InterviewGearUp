When should you use `useMemo` and `useCallback`, and what is the cost of premature optimization?

Frontend engineer · Gear 2 (Mid-level) · React · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

useMemo caches the result of an expensive calculation and useCallback caches a function reference, both until their dependencies change. Use them when a calculation is genuinely slow or when a stable reference is needed for a memoised child or another hook's dependency. Used everywhere they add overhead and complexity, so measure first.

Explained in depth

What they do

const sorted = useMemo(() => sortLargeList(items), [items]);
const onSelect = useCallback((id) => setSelected(id), []);

useMemo(fn, deps) returns the previous value if deps are unchanged. useCallback(fn, deps) is the same as useMemo(() => fn, deps): it returns the same function reference.

When they help

  1. Expensive computation (filtering and sorting thousands of rows) that would otherwise run on every render.
  2. Referential equality: passing an object or function to a child wrapped in React.memo, or as a dependency of useEffect, so it does not change on each render.

When they do not

  • Cheap work: the memoisation itself costs time and memory, because React must store the value and compare dependencies each render.
  • A callback passed to a child that is not memoised: the child re-renders anyway.
  • If dependencies change on every render, the cache is never used.

Cost of premature optimisation

More code, harder reading, stale-closure bugs from wrong dependency lists, and no measured benefit. Profile with React DevTools first, and find out what actually re-renders and why.

Alternatives

Move state down, split components, lift expensive work out of render, or let the React Compiler (which memoises automatically) handle it, so manual memos are needed less often.

Likely follow-ups

  • What does useCallback actually save if the child is not wrapped in memo?
  • How does the React Compiler change this advice?
  • Why can stale dependencies cause bugs?
