How do Service Workers intercept network requests to implement offline-first PWA caching strategies?

Frontend engineer · Gear 3 (Senior) · Performance · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

A service worker is a script that runs separately from the page and sits between it and the network. Its fetch handler can answer from the Cache API, so you choose a strategy per resource: cache-first for versioned static assets, network-first or stale-while-revalidate for content, with a cache fallback for offline use.

Explained in depth

Lifecycle

Register the worker (HTTPS or localhost only), then it goes install (precache the app shell), waiting, and activate (delete old caches). A new version waits until old tabs close unless you call skipWaiting() and clients.claim(), which is convenient but can mix old page code with new worker code.

Strategies

StrategyUse forTrade-off
Cache firstHashed, immutable assetsFast; stale until the version changes
Network firstHTML, API dataFresh; slow when offline or flaky
Stale-while-revalidateContent that can lag a littleFast now, updated for next time
Network only / cache onlyAuth calls, or precached shellSimple
self.addEventListener('fetch', (event) => {
  if (event.request.method !== 'GET') return;          // never cache writes
  event.respondWith(
    fetch(event.request)
      .then((res) => {
        const copy = res.clone();
        caches.open('v2').then((c) => c.put(event.request, copy));
        return res;
      })
      .catch(() => caches.match(event.request).then((hit) => hit || caches.match('/offline.html')))
  );
});

Pitfalls

  • Version your cache names and delete old ones in activate, or users get stuck on stale files.
  • Do not cache authenticated or personalised responses in shared caches, and watch opaque (cross-origin, no-CORS) responses and storage quotas.
  • A buggy worker can break the whole site, so keep a kill-switch plan; the browser re-checks the worker script itself on navigation.
  • Libraries such as Workbox implement these strategies, expiry and update flows for you.
