How do you find the longest substring without repeating characters using a sliding window and hash map?

Software engineer (core) · Gear 2 (Mid-level) · Algorithms · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

Use a sliding window with a hash map that stores the last index of each character. Move the right end across the string; when a character repeats inside the window, jump the left end to just after its previous position. The window always holds distinct characters, and the best length is tracked in a single O(N) pass.

Explained in depth

Approach

def longest_unique(s):
    last = {}                  # char -> last index seen
    left = best = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:
            left = last[ch] + 1          # skip past the earlier copy
        last[ch] = right
        best = max(best, right - left + 1)
    return best

# 'abcabcbb' -> 3 ('abc'),  'bbbbb' -> 1,  'pwwkew' -> 3 ('wke')

Why last[ch] >= left matters

An earlier occurrence of the character that lies before left is outside the window and must not move left backwards. Without this check you get wrong answers on inputs like abba.

Complexity

  • Time O(N): right visits each position once and left never moves backwards.
  • Space O(min(N, alphabet size)) for the map.

Variation

A set-based version shrinks the window one step at a time with a while loop while the new character is in the set. It has the same O(N) bound but more steps. To return the substring, record the start of the best window.
