Derive the Self-Attention mechanism mathematically: Query, Key, Value matrices and Scaled Dot-Product.

ML / AI engineer · Gear 3 (Senior) · Transformers · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

Project the input X into queries, keys and values with learned matrices. Compute scores QK^T, scale by sqrt(d_k), softmax each row into attention weights, and multiply by V. Each output position becomes a weighted average of all value vectors, weighted by how well its query matches each key.

Explained in depth

Steps

For a sequence of n tokens, X has shape n x d_model.

Q = X W_Q    (n x d_k)
K = X W_K    (n x d_k)
V = X W_V    (n x d_v)

Attention(Q, K, V) = softmax( Q K^T / sqrt(d_k) ) V
  1. Q K^T is an n x n matrix of dot-product similarities between every query and every key.
  2. Divide by sqrt(d_k) to keep the logits at a stable scale.
  3. Apply softmax across each row, so the weights for one query sum to 1.
  4. Multiply by V: each output row is a weighted average of the value vectors.

Intuition

The query says what a token is looking for, the key says what each token offers, and the value is the information that is passed on. A causal mask (setting scores above the diagonal to minus infinity before the softmax) stops decoder tokens from attending to the future.

Multi-head attention

Run h attention heads with smaller dimensions (d_k = d_model / h), each with its own projections, concatenate the outputs and apply an output matrix W_O. Different heads can learn different relationships.

Properties

  • Cost is O(n^2 * d) time and O(n^2) memory for the score matrix, which is why long sequences are expensive (FlashAttention and sparse variants address this).
  • Attention treats the input as a set, so positional information has to be added through encodings.
  • Everything is matrix multiplication, so it parallelises well on GPUs.
