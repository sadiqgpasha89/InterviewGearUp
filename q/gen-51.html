Explain bitwise operators (AND, OR, XOR, NOT, Shifts) and how XOR cancels identical numbers.

Software engineer (core) · Gear 1 (Junior) · Bit manipulation · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

AND, OR and XOR combine bits pairwise, NOT flips every bit, and shifts move bits left or right (a left shift by k multiplies by 2^k). XOR has two key properties: x ^ x = 0 and x ^ 0 = x, so XORing a whole array cancels every value that appears twice and leaves the one that appears once.

Explained in depth

Operators

OperatorMeaningExample (4-bit)
a & b1 only if both bits are 11100 & 1010 = 1000
a | b1 if either bit is 11100 | 1010 = 1110

a << kshift left, multiply by 2^k0011 << 1 = 0110
a >> kshift right, divide by 2^k0110 >> 1 = 0011

XOR properties

  • x ^ x = 0
  • x ^ 0 = x
  • It is commutative and associative, so order does not matter.

Single number problem

def single_number(nums):
    r = 0
    for x in nums:
        r ^= x        # pairs cancel, the unique value remains
    return r

This takes O(N) time and O(1) space.

Handy tricks

  • Test bit i: (x >> i) & 1. Set it: x | (1 << i). Clear it: x & ~(1 << i). Toggle it: x ^ (1 << i).
  • Power of two: x > 0 and (x & (x - 1)) == 0.
  • Right shift of a negative signed number is arithmetic in most languages (the sign bit is copied); use an unsigned or logical shift when you need zero fill.
