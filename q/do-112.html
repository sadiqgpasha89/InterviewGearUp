What is a CDN and how does it improve performance and reliability?

DevOps / SRE / Cloud · Gear 1 (Junior) · Networking · Difficulty: easy · AI-drafted, not yet reviewed by a person

In 30 seconds

A content delivery network is a globally distributed set of edge servers that cache copies of content close to users. Requests are routed to a nearby edge, which serves cached responses with low latency or fetches from the origin on a miss. CDNs cut load on origin servers, absorb traffic spikes and DDoS attacks, and can terminate TLS and compress content.

Explained in depth

How it works

  1. The user requests cdn.example.com/app.js. DNS or anycast routing sends the request to the nearest edge location (PoP).
  2. Cache hit: the edge returns the stored copy immediately.
  3. Cache miss: the edge fetches from the origin (your servers or object storage), returns it, and stores it according to caching headers (Cache-Control, s-maxage) for later users.

Benefits

  • Lower latency: content travels a shorter distance, with optimised connections to the origin and modern protocols (HTTP/2, HTTP/3).
  • Reduced origin load and cost: the edge serves most requests, so you need fewer servers and less bandwidth.
  • Availability: edges can serve stale content if the origin is down (stale-if-error), and absorb spikes.
  • Security: DDoS protection, a web application firewall, bot management, TLS termination, and hiding origin addresses.
  • Edge compute: functions at the edge (Cloudflare Workers, Lambda@Edge) for redirects, personalisation and authentication.

What to cache

Static assets (JS, CSS, images, video) with long lifetimes and fingerprinted filenames; semi-static pages with short TTLs; API responses that are public. Do not cache personalised or private responses unless the cache key includes what makes them different, and set Vary correctly.

Operations

  • Invalidation (purge) after changes, or avoid it by versioned URLs.
  • Monitor cache hit ratio, origin latency and error rates, and use an origin shield (a middle cache tier) to reduce origin fetches.
  • Common providers: CloudFront, Cloudflare, Fastly, Akamai.
