Explain event bubbling, event capturing, and how event delegation improves performance.

Frontend engineer · Gear 2 (Mid-level) · DOM · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

An event travels in three phases: capture from the window down to the target, the target itself, then bubbling back up. Listeners run on bubbling by default. Event delegation puts one listener on a common ancestor and uses event.target to find which child was hit, so it needs fewer listeners and also covers elements added later.

Explained in depth

Phases

  1. Capture: from window down through ancestors to the target's parent.
  2. Target: the element itself.
  3. Bubble: back up through the ancestors.

addEventListener('click', fn) listens in the bubble phase. Pass { capture: true } to listen while the event travels down. event.target is the element that was actually hit, event.currentTarget the element the listener is attached to. stopPropagation() stops the event travelling further, and preventDefault() is a different thing: it cancels the default browser action.

Event delegation

list.addEventListener('click', (e) => {
  const item = e.target.closest('li[data-id]');   // handles clicks on children of the li too
  if (!item || !list.contains(item)) return;
  open(item.dataset.id);
});

Benefits

  • One listener instead of thousands saves memory and setup time.
  • Elements added or removed later are handled automatically, with no re-binding.
  • Less cleanup, so fewer listener leaks.

Caveats

  • Some events do not bubble (focus, blur, mouseenter). Use focusin and focusout, or capture.
  • If a child calls stopPropagation(), the delegated listener never sees the event.
  • Use closest() because the click may land on a nested element such as an icon inside a button.
  • For very high-frequency events (mousemove, scroll), keep the handler cheap and consider throttling.
  • Frameworks like React use delegation internally, attaching listeners at the root.

  • What is the difference between stopPropagation and preventDefault?
