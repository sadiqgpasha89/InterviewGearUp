How does Huffman Coding build an optimal prefix-free binary tree for lossless data compression?

Software engineer (core) · Gear 3 (Senior) · Algorithms · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

Huffman coding builds a prefix-free binary code that gives frequent symbols short codes. Put every symbol in a min-heap by frequency, repeatedly merge the two lowest-frequency nodes into a parent whose weight is their sum, and when one tree remains, read each code from the root-to-leaf path. It is optimal among symbol-by-symbol prefix codes.

Explained in depth

Algorithm

  1. Count the frequency of each symbol.
  2. Create a leaf per symbol and put them in a min-heap by frequency.
  3. Pop the two smallest nodes, create a parent with their combined weight, and push it back.
  4. Repeat until one node remains: the root.
  5. Assign 0 to each left edge and 1 to each right edge; a symbol's code is the path from the root to its leaf.
import heapq, itertools

def huffman(freqs):                       # freqs: {symbol: count}
    tie = itertools.count()
    heap = [(f, next(tie), s) for s, f in freqs.items()]
    heapq.heapify(heap)
    while len(heap) > 1:
        f1, _, a = heapq.heappop(heap)
        f2, _, b = heapq.heappop(heap)
        heapq.heappush(heap, (f1 + f2, next(tie), (a, b)))
    codes = {}
    def walk(node, prefix=''):
        if isinstance(node, tuple):
            walk(node[0], prefix + '0')
            walk(node[1], prefix + '1')
        else:
            codes[node] = prefix or '0'
    walk(heap[0][2])
    return codes

Properties

  • Prefix-free: symbols sit at leaves, so no code is a prefix of another and decoding is unambiguous without separators.
  • Optimal: the two rarest symbols belong at the deepest level as siblings, and merging them reduces to a smaller instance of the same problem (an exchange argument).
  • Time O(n log n) for n symbols.

Limits

The code length per symbol is a whole number of bits, so it cannot reach the entropy exactly; arithmetic coding does better. The decoder needs the tree or the frequency table, which is sent as a header. DEFLATE (zip, gzip, PNG) uses Huffman codes after LZ77.
