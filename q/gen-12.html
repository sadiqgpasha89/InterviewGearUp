How do you reverse a singly linked list in-place both iteratively and recursively?

Software engineer (core) · Gear 1 (Junior) · Algorithms · Difficulty: easy · AI-drafted, not yet reviewed by a person

In 30 seconds

Iteratively, walk the list with three pointers (prev, curr, next) and flip each next pointer to point backwards; this takes O(n) time and O(1) space. Recursively, reverse the rest of the list and then attach the head at the end, which is O(n) time but O(n) stack space.

Explained in depth

Iterative (preferred)

def reverse(head):
    prev = None
    curr = head
    while curr:
        nxt = curr.next      # save the rest
        curr.next = prev     # flip the link
        prev = curr          # advance prev
        curr = nxt           # advance curr
    return prev              # new head

Each node is visited once. Only three pointers are used, so the extra space is O(1).

Recursive

def reverse(head):
    if head is None or head.next is None:
        return head
    new_head = reverse(head.next)   # reverse everything after head
    head.next.next = head           # the next node now points back to head
    head.next = None                # head becomes the tail
    return new_head

The call stack holds one frame per node, so the space is O(n) and a very long list can overflow the stack.

Interview tips

  • Draw three or four nodes and step through the pointer changes.
  • Check edge cases: empty list, one node, two nodes.
  • The common bug is losing the rest of the list by overwriting next before saving it.

Likely follow-ups

  • What is the recursion depth risk for a list of a million nodes?
  • How would you reverse only the nodes between positions m and n?
  • How would you reverse the list in groups of k nodes?
