How does Kosaraju's two-pass DFS algorithm identify Strongly Connected Components (SCC) in directed graphs?

Software engineer (core) · Gear 3 (Senior) · Graphs · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

Kosaraju's algorithm runs a DFS on the graph to record finish order, then a second DFS on the transposed graph in decreasing finish time. Each tree of the second pass is exactly one strongly connected component, in O(V + E) time.

Explained in depth

Definition

In a directed graph, two vertices are in the same strongly connected component (SCC) if each can reach the other. SCCs partition the vertices. Contracting each SCC to a single node yields the condensation graph, which is always a DAG.

Algorithm

  1. Run DFS over all vertices of G. Push each vertex on a stack (or list) when it finishes.
  2. Build the transpose graph G^T (reverse all edges).
  3. Pop vertices from the stack (latest finish first). For each unvisited vertex v, run DFS in G^T; all vertices reached form one SCC.
def kosaraju(n, adj):
    seen, order = [False] * n, []
    def dfs1(u):
        seen[u] = True
        for v in adj[u]:
            if not seen[v]: dfs1(v)
        order.append(u)                      # finish time order
    for u in range(n):
        if not seen[u]: dfs1(u)
    radj = [[] for _ in range(n)]
    for u in range(n):
        for v in adj[u]: radj[v].append(u)
    comp, c = [-1] * n, 0
    def dfs2(u):
        comp[u] = c
        for v in radj[u]:
            if comp[v] == -1: dfs2(v)
    for u in reversed(order):
        if comp[u] == -1: dfs2(u); c += 1
    return comp, c                          # component id per vertex, count

Why it works

Let C and C' be SCCs with an edge C -> C' in G. The vertex with the latest finish time overall belongs to a source component of the condensation (nothing points into it). In G^T edges between components are reversed, so starting at that vertex the DFS can only reach vertices of its own component: the edges that would leave it point backwards in G^T. Removing that component and repeating gives the next one. A formal proof shows max finish(C) > max finish(C') whenever there is an edge C -> C'.

Complexity

Two DFS passes plus building the transpose: O(V + E) time and O(V + E) space.

Comparison with Tarjan

Tarjan finds SCCs in a single DFS with a stack and low-link values; it avoids building the transpose and is usually faster, but Kosaraju is easier to explain and implement correctly. Gabow's path-based algorithm is another one-pass variant.

Applications

  • 2-SAT: build an implication graph; the formula is satisfiable iff no variable and its negation share an SCC.
  • Detecting cyclic dependencies and topologically ordering the condensation (build systems, package managers, deadlock detection).
  • Compiler optimisations (call graph, dataflow), web graph analysis, and model checking.

Pitfalls

Recursion depth on large graphs (use iterative DFS), forgetting to reset visited state between passes, and mixing up the finish order direction in the second pass.
