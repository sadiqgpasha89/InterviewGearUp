Derive the backpropagation algorithm using the calculus chain rule for neural network weights.

ML / AI engineer · Gear 2 (Mid-level) · Deep Learning · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

Backpropagation applies the chain rule layer by layer from the loss backwards, reusing the values stored in the forward pass. For each layer it computes the error signal delta at the pre-activation, then the weight gradient as the outer product of delta and the layer's input, and passes delta back through the transposed weights, multiplied by the activation's derivative.

Explained in depth

Setup (two-layer network)

z1 = W1 x + b1, a1 = f(z1), z2 = W2 a1 + b2, y_hat = z2, loss L = 0.5 * (y_hat - y)^2.

Backward pass with the chain rule

  1. Output error: dL/dz2 = delta2 = y_hat - y.
  2. Gradients for layer 2:
  • dL/dW2 = delta2 * a1^T (outer product of the error and the layer's input)
  • dL/db2 = delta2
  1. Propagate to the hidden layer: dL/da1 = W2^T delta2.
  2. Through the activation: delta1 = dL/dz1 = (W2^T delta2) * f'(z1) (elementwise).
  3. Gradients for layer 1: dL/dW1 = delta1 * x^T, dL/db1 = delta1.

General rule for layer l: delta_l = (W_{l+1}^T delta_{l+1}) * f'(z_l), then dW_l = delta_l * a_{l-1}^T.

Update

W = W - lr * dL/dW (or via an optimiser such as Adam). For a batch, average the gradients.

Key insights

  • The cost of the backward pass is about the same as two forward passes, since it reuses stored z and a values; that is why memory goes up with depth.
  • With softmax and cross-entropy, the output error simplifies to probs - one_hot_label.
  • Repeated multiplication by W^T and f' explains vanishing (products below 1) and exploding (above 1) gradients.
  • Modern frameworks implement this with automatic differentiation: each operation knows its local derivative and the engine applies the chain rule over the computation graph.
  • Check an implementation with a numerical gradient: (L(w + eps) - L(w - eps)) / (2 * eps).

Likely follow-ups

  • How does automatic differentiation generalise these formulas?
