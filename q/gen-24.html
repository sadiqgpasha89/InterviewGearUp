Explain Disjoint Set Union (Union-Find) with path compression and union by rank optimizations.

Software engineer (core) · Gear 2 (Mid-level) · Data structures · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

Union-Find keeps disjoint sets in a forest. find returns a set's root, union links two roots. With path compression and union by rank or size, each operation costs amortised near-constant time (inverse Ackermann), which makes it ideal for connectivity and Kruskal's algorithm.

Explained in depth

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]   # path halving
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False                 # already connected
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra             # attach the smaller tree
        self.size[ra] += self.size[rb]
        return True

The two optimisations

  • Union by rank or size: attach the smaller tree under the larger so trees stay shallow (height O(log N)).
  • Path compression: during find, point nodes closer to the root, flattening the tree for later queries.
  • Together they give amortised O(alpha(N)) per operation, where alpha is the inverse Ackermann function, below 5 for any realistic input.

Where it is used

Counting connected components, detecting a cycle when adding an edge to an undirected graph (union returns false), Kruskal's minimum spanning tree, merging accounts or islands as input arrives, and offline connectivity queries. It cannot split sets, so it does not support edge deletion.
