How does binary search on the answer space solve optimization problems like Koko Eating Bananas?

Software engineer (core) · Gear 3 (Senior) · Algorithms · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

Binary search on the answer applies when the answer lies in a numeric range and feasibility is monotonic: if speed k works then any larger speed works. Search the range for the smallest feasible value, using a check function that simulates the problem. Koko Eating Bananas checks, for a speed, whether the total hours needed is at most h.

Explained in depth

The pattern

Instead of searching an array, search the range of possible answers. It works when:

  1. The answer is a number in a known range [lo, hi].
  2. A function feasible(x) can be evaluated quickly.
  3. Feasibility is monotonic: false for small x, then true from some point on (or the reverse).

Koko Eating Bananas

Piles of bananas, h hours; find the minimum speed k (bananas per hour) so all piles are eaten in h hours. Eating a pile of p bananas at speed k takes ceil(p / k) hours.

def min_eating_speed(piles, h):
    def hours(k):
        return sum((p + k - 1) // k for p in piles)
    lo, hi = 1, max(piles)             # a speed of max(piles) always works if h >= len(piles)
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if hours(mid) <= h:
            hi = mid                   # feasible, try slower
        else:
            lo = mid + 1               # too slow
    return lo

Complexity

O(n log(max pile)): each check is O(n) and there are log(max) steps.

Other problems with the same shape

Capacity to ship packages within D days, split array largest sum, minimum days to make m bouquets, aggressive cows and square root approximations. When the problem asks to minimise a maximum or maximise a minimum, think of this pattern.
