Compare Positional Encodings: Sinusoidal encodings versus Learned embeddings versus RoPE (Rotary Position Embedding).

ML / AI engineer · Gear 3 (Senior) · Transformers · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

Transformers have no inherent sense of order, so positions must be injected. Sinusoidal encodings add fixed sine and cosine patterns; learned embeddings train a vector per position but cap the context length; RoPE rotates query and key vectors by an angle proportional to position, so attention depends on relative distance and extrapolates and scales better, which is why most recent LLMs use it.

Explained in depth

The need

Self-attention treats its input as a set: permuting tokens permutes the outputs in the same way. Without position information, "dog bites man" and "man bites dog" look alike.

Sinusoidal (original transformer)

Add a fixed vector to each token embedding: PE(pos, 2i) = sin(pos / 10000^(2i/d)), PE(pos, 2i+1) = cos(pos / 10000^(2i/d)) Different dimensions use different wavelengths; the encoding of position pos + k is a linear function of that of pos, so relative offsets are easy to learn. No parameters, and it can in principle handle longer sequences, though quality often degrades beyond the training length.

Learned absolute embeddings

A trainable matrix with one row per position (BERT, GPT-2). Flexible, but limited to the maximum length seen in training and does not generalise to longer inputs.

RoPE (rotary position embedding)

Applies a rotation to each pair of dimensions of the query and key, with angle proportional to the token's position. The dot product of a rotated query at position m and a rotated key at position n depends on m - n, so attention naturally uses relative distance, without adding anything to the embeddings. Benefits: relative-position behaviour, good long-range decay, and it can be extended to longer contexts by scaling the rotation frequencies (position interpolation, NTK or YaRN scaling). Used in LLaMA, Mistral, Qwen and many others.

ALiBi is another alternative: it adds a linear distance penalty to attention scores.
