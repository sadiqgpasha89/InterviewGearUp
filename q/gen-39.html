How do you implement binary search to find the lower bound (first occurrence) and upper bound in sorted arrays?

Software engineer (core) · Gear 2 (Mid-level) · Algorithms · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

For a lower bound, find the first index whose value is at least the target; for an upper bound, find the first index whose value is greater than the target. Use binary search with a half-open range and, on a match, keep searching left (lower bound) instead of returning. Both run in O(log N), and the pair gives the count of a value.

Explained in depth

Lower bound (first index with a[i] >= target)

def lower_bound(a, target):
    lo, hi = 0, len(a)            # hi is exclusive
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if a[mid] < target:
            lo = mid + 1
        else:
            hi = mid              # keep mid, it could be the answer
    return lo

Upper bound (first index with a[i] > target)

Change the comparison to a[mid] <= target:

def upper_bound(a, target):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if a[mid] <= target:
            lo = mid + 1
        else:
            hi = mid
    return lo

Using them

  • First occurrence: i = lower_bound(a, t), valid if i < len(a) and a[i] == t.
  • Last occurrence: upper_bound(a, t) - 1.
  • Count: upper_bound - lower_bound.
  • Insertion point that keeps the array sorted: the lower bound. These match Python's bisect_left and bisect_right.

Tips

The invariant is that the answer always lies in [lo, hi]. Using lo < hi with hi = mid avoids the infinite loops you get from mixing conventions.
