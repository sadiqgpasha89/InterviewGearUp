What is Cilium CNI and how does extended Berkeley Packet Filter (eBPF) accelerate pod networking?

DevOps / SRE / Cloud · Gear 4 (Lead / Staff) · Kubernetes · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

Cilium is a Kubernetes networking plugin built on eBPF, small programs that run safely inside the Linux kernel. It implements pod networking, service load balancing, network policy and observability without long iptables chains, using hash-map lookups instead of linear rule scans, and it can skip parts of the kernel network stack.

Explained in depth

The iptables problem

kube-proxy in iptables mode creates rules for every Service and endpoint. Packets are matched against them sequentially, so lookup cost and rule update time grow with the cluster, and connection tracking adds overhead.

What eBPF changes

eBPF programs attach to kernel hooks (traffic control, XDP at the network driver, sockets) and use hash maps for lookups, which are constant time regardless of how many Services exist. Cilium can replace kube-proxy entirely, and even do socket-level load balancing, choosing the backend at connect() time so that packets need no per-packet NAT. Native routing and host routing in eBPF can bypass parts of the stack, lowering latency and CPU.

Features beyond speed

  • Identity-based network policy: policies refer to labels and workload identities, not IP addresses that change constantly, and can enforce rules at L3, L4 and L7 (HTTP, gRPC, DNS names).
  • Hubble: flow-level observability (who talked to whom, dropped packets, DNS) without sidecars.
  • Transparent encryption (WireGuard or IPsec), egress gateways and multi-cluster connectivity (ClusterMesh).

Trade-offs

  • Needs a reasonably recent Linux kernel, and some features have specific requirements.
  • eBPF is harder to debug than iptables, and the team needs to learn new tools.
  • On small clusters the performance gain may be modest. The strongest benefits show at scale and with policy-heavy or latency-sensitive workloads.

Cilium is one of several CNIs; others such as Calico also offer an eBPF dataplane.
