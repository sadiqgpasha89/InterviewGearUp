How do you remove duplicate rows in SQL while keeping the most recent one?

Data engineer · Gear 1 (Junior) · SQL · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

Rank rows within each duplicate group using ROW_NUMBER() OVER (PARTITION BY key ORDER BY updated_at DESC) and keep rank 1. SELECT DISTINCT only removes rows that are identical in every selected column, so it cannot choose which of several different versions to keep.

Explained in depth

SELECT *
FROM (
  SELECT t.*,
         ROW_NUMBER() OVER (
           PARTITION BY customer_id
           ORDER BY updated_at DESC, id DESC
         ) AS rn
  FROM customers t
) x
WHERE rn = 1;
  • PARTITION BY defines what counts as a duplicate; ORDER BY decides which row wins. Add a tie-breaker (here id) so the result is deterministic.
  • To delete duplicates in place, delete the rows where rn > 1, using a CTE or the table's physical row identifier.
  • GROUP BY with MAX(updated_at) also works but needs a join back to fetch the other columns.
  • DISTINCT ON (customer_id) in PostgreSQL, and QUALIFY in Snowflake and BigQuery, are shorter forms of the same idea.

In pipelines, prevent duplicates at the source with a unique key and an upsert (MERGE) so that cleanup is not needed.

Likely follow-ups

  • How does RANK differ from ROW_NUMBER when there are ties?
  • How would you prevent duplicates from arriving in the first place?
