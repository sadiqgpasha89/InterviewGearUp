Explain the Multilayer Perceptron (MLP) forward pass and matrix multiplication mechanics.

ML / AI engineer · Gear 2 (Mid-level) · Deep Learning · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

An MLP layer computes z = Wx + b and then applies a nonlinearity. With batches, the whole layer is one matrix multiplication: a batch matrix of shape (batch, in_features) times weights (in_features, out_features) plus bias, then an activation. Stacking layers feeds each output into the next, ending in logits or predictions.

Explained in depth

One layer

For a single sample x (vector of size d_in), the layer produces h = f(W x + b), where W has shape (d_out, d_in), b has shape (d_out) and f is an activation such as ReLU.

Batched form

Frameworks store a batch as a matrix X of shape (B, d_in) and compute: H = f(X W^T + b) giving shape (B, d_out). The bias is broadcast across the batch.

Example: 784 to 128 to 10 for MNIST, batch 32

import numpy as np
X  = np.random.randn(32, 784)
W1 = np.random.randn(784, 128) * 0.01;  b1 = np.zeros(128)
W2 = np.random.randn(128, 10)  * 0.01;  b2 = np.zeros(10)

H = np.maximum(0, X @ W1 + b1)        # (32,128), ReLU
logits = H @ W2 + b2                  # (32,10)
probs = np.exp(logits - logits.max(1, keepdims=True))
probs /= probs.sum(1, keepdims=True)  # softmax over classes

Parameters: 784*128 + 128 + 128*10 + 10 = 101,770.

Key points

  • Without a nonlinearity, stacked linear layers collapse into one linear map, so depth adds nothing.
  • The forward pass is dominated by matrix multiplications, which GPUs and tensor cores do very efficiently; cost per layer is about B * d_in * d_out multiply-adds.
  • Intermediate activations are stored for the backward pass, so memory grows with batch size and depth.
  • The final layer outputs logits; use softmax with cross-entropy for classification (numerically stable fused losses are preferred) and no activation for regression.
