How do SHAP (Shapley Additive Explanations) values provide local and global feature attributions?

ML / AI engineer · Gear 3 (Senior) · Explainability · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

SHAP assigns each feature a Shapley value: its average marginal contribution to a prediction across all feature coalitions, derived from cooperative game theory. The values for one prediction sum to the difference between that prediction and the baseline expectation, giving local explanations. Averaging absolute SHAP values over a dataset gives global importance, and plots reveal direction and interactions.

Explained in depth

Origin

In cooperative game theory, players jointly produce a payout, and the Shapley value is the unique fair division satisfying efficiency, symmetry, dummy and additivity axioms. SHAP (Lundberg and Lee, 2017) treats features as players and the prediction as the payout.

Definition

For model f, instance x, and feature i: φᵢ = Σ over subsets S ⊆ F\{i} [ |S|! (|F|−|S|−1)! / |F|! ] · ( f_{S∪{i}}(x) − f_S(x) ) where f_S is the model's expected output when only the features in S are known (others marginalised over a background distribution). It averages the marginal contribution of feature i over all orderings in which features can be added.

Additive property (local accuracy): f(x) = φ₀ + Σ φᵢ, where φ₀ = E[f(X)] is the base value. So each prediction decomposes exactly into feature contributions: positive φ pushes the prediction above the average, negative pushes below.

Computation

Exact computation needs 2^|F| model evaluations, infeasible for many features. Estimators:

  • TreeSHAP: polynomial-time exact algorithm for tree ensembles (XGBoost, LightGBM, CatBoost, random forests) using the tree structure; very fast.
  • KernelSHAP: model-agnostic weighted linear regression approximation using sampled coalitions; slow, needs background samples.
  • DeepSHAP / GradientSHAP / Integrated-gradients-style: neural networks (DeepLIFT-based).
  • LinearSHAP: closed form for linear models.
  • PermutationExplainer and partition explainers for text and images with structured masking (grouped tokens, superpixels).
import shap, xgboost
model = xgboost.XGBClassifier().fit(X_train, y_train)
explainer = shap.TreeExplainer(model)
sv = explainer(X_test)                         # shap.Explanation: values, base_values, data
shap.plots.waterfall(sv[0])                    # local: one prediction
shap.plots.beeswarm(sv)                        # global: distribution of effects per feature
shap.plots.bar(sv)                             # global importance = mean(|SHAP|)
shap.plots.scatter(sv[:, "income"], color=sv)  # dependence with interactions

Local versus global

  • Local explanation: for a loan application, the waterfall shows base 0.12 → +0.18 (debt ratio) +0.07 (recent delinquencies) −0.05 (income) = 0.32. Useful for adverse-action reasons, debugging and customer-facing explanations.
  • Global explanation: aggregate SHAP values across many instances: mean absolute value ranks features by overall impact; beeswarm plots show direction (higher feature values increase or decrease the output) and spread; dependence plots show nonlinear effects and interactions (SHAP interaction values for trees); clustering of SHAP values finds subpopulations.

Practical considerations

  1. Units: for classifiers, tree SHAP explains the margin (log-odds) by default; use model_output="probability" where supported. Be explicit about the output scale.
  2. Background data and conditional versus interventional: the way missing features are handled (marginal/interventional versus conditional on correlated features) changes attributions. With correlated features, credit is split arbitrarily among them, and interventional SHAP can create unrealistic samples.
  3. Not causal: SHAP shows how the model uses features, not how the real world works; do not claim that changing a feature would change the outcome.
  4. Stability and cost: sample-based estimators vary; use enough background rows (50 to 500, or k-means summaries); sample test rows for global plots.
  5. Fairness and governance: use for audits, feature selection, drift analysis (SHAP value drift), debugging leakage (a suspicious ID-like feature with huge impact), and regulatory documentation.
  6. Compare with LIME (local surrogate, less consistent), permutation importance, partial dependence, and counterfactuals.

Pitfalls

Over-interpreting attributions for correlated features, explaining the wrong output scale, presenting SHAP as causal, slow KernelSHAP on large data, and ignoring that explanations depend on the model, not the data alone.
