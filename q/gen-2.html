Given an array of numbers and a target, return the indices of two numbers that add up to the target.

Software engineer (core) · Gear 1 (Junior) · Arrays and hashing · Not yet reviewed by a person (origin not recorded)

In 30 seconds

Scan once with a hash map from value to index: for each number, check whether target minus the number was already seen. O(n) time, O(n) space.

Explained in depth

The brute force tries every pair, which is O(n^2). The map version trades memory for speed:

function twoSum(nums, target) {
  const seen = new Map();            // value -> index
  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i];
    if (seen.has(need)) return [seen.get(need), i];
    seen.set(nums[i], i);
  }
  return [];                         // no pair found
}

Checking for the complement before inserting the current number stops you using the same element twice, and still handles duplicates: for [3, 3] and target 6, the first 3 is stored and the second finds it.

Edge cases to mention: empty array, no solution, negative numbers. If the array is already sorted and you must use O(1) extra space, use two pointers moving inward, but note that you then return values unless you track original indices.

Likely follow-ups

  • What if there are many valid pairs and you need all unique pairs?
  • How would you extend it to three numbers?
  • What changes if the data does not fit in memory?
