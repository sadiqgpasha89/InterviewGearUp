Explain Core Web Vitals: Largest Contentful Paint (LCP), Interaction to Next Paint (INP), and Cumulative Layout Shift (CLS).

Frontend engineer · Gear 3 (Senior) · Performance · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

Core Web Vitals measure loading, responsiveness and visual stability from real users. LCP is when the largest content element renders (good is 2.5 s or less), INP is the latency of interactions across the visit (good is 200 ms or less), and CLS sums unexpected layout shifts (good is 0.1 or less), each judged at the 75th percentile.

Explained in depth

MetricMeasuresGood threshold
LCP Largest Contentful PaintWhen the largest image or text block in the viewport is rendered2.5 s or less
INP Interaction to Next PaintHow long it takes the page to visually respond to clicks, taps and key presses, over the whole visit200 ms or less
CLS Cumulative Layout ShiftHow much visible content moves unexpectedly0.1 or less

INP replaced First Input Delay as the responsiveness metric in 2024, because FID only looked at the first interaction's input delay while INP covers every interaction and the full time to the next paint.

Improving each one

  • LCP: serve the hero image early with <link rel=preload> or fetchpriority=high, never lazy-load the LCP image, cut server response time (cache, CDN), avoid render-blocking CSS and JS.
  • INP: break up long tasks, defer non-critical and third-party scripts, avoid heavy work in event handlers, reduce hydration cost, and give instant visual feedback before slow work.
  • CLS: set width and height or aspect-ratio on images and embeds, reserve space for ads and banners, avoid inserting content above existing content, and use font-display with metric-matched fallback fonts.

Measuring

Field data from real users (Chrome UX Report, the web-vitals library sending to your analytics) is what counts, judged per page at the 75th percentile. Lab tools such as Lighthouse are good for debugging but do not capture real interactions; Total Blocking Time is only a rough proxy for INP.

Likely follow-ups

  • Why is field data preferred over a Lighthouse score?
  • How would you find which interaction causes a poor INP?
  • How can a web font cause both LCP and CLS problems?
