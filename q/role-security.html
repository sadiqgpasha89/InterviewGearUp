Gear 1: Junior (0 to 2 years)

  • What is the difference between encoding, encryption and hashing?
  • Explain SQL injection and cross-site scripting, and how to prevent each.
  • Explain the OWASP Top 10 vulnerabilities and why they represent common application security risks.
  • What is the fundamental difference between Authentication (AuthN) and Authorization (AuthZ)?
  • What is the principle of least privilege and how do you apply it?
  • How should an application store user passwords?
  • What is the CIA triad in information security?
  • What is the difference between a vulnerability, a threat and a risk?
  • What is a firewall, and how do stateless, stateful and application-layer firewalls differ?
  • What is HTTPS, and what does the padlock in the browser actually guarantee?
  • What is a man-in-the-middle (MITM) attack, and how do you defend against it?
  • What is phishing, and how can individuals and organisations defend against it?
  • What is defence in depth, and why is relying on a single security control risky?
  • What are the main types of malware (virus, worm, trojan, ransomware, spyware), and how do they differ?
  • What is the difference between input validation and output encoding, and why do you need both?

Gear 2: Mid-level (2 to 5 years)

  • How does the TLS handshake work?
  • Explain the OAuth 2.0 authorization code flow with PKCE.
  • Explain SQL Injection (SQLi): Classic, Blind (Boolean/Time-based), and why ORMs are not inherently immune.
  • Compare Cross-Site Scripting (XSS) types: Stored, Reflected, and DOM-based XSS with remediation techniques.
  • Explain Cross-Site Request Forgery (CSRF): Attack mechanics, Anti-CSRF tokens, and `SameSite` cookie flags.
  • Explain Broken Object-Level Authorization (BOLA/IDOR) and how to enforce object ownership checks.
  • Explain XML External Entity (XXE) attacks and how disabling external DTD parsing prevents file exfiltration.
  • What are common Security Misconfigurations in cloud infrastructure, and how do you detect exposed S3 buckets?
  • What is Software Composition Analysis (SCA) and how does it detect vulnerabilities in open-source dependencies?
  • Compare Static Application Security Testing (SAST) and Dynamic Application Security Testing (DAST).
  • Compare Symmetric Encryption (AES-GCM) and Asymmetric Encryption (RSA, ECC): Speed and use cases.
  • Why is AES-GCM preferred over AES-CBC for symmetric encryption (Authenticated Encryption)?
  • Compare cryptographic hash functions: SHA-256 versus SHA-3 and the importance of collision resistance.
  • Explain password hashing best practices: Why are Argon2id, bcrypt, and scrypt preferred over SHA-256?
  • How do digital signatures guarantee non-repudiation and data integrity using asymmetric key pairs?
  • Explain OAuth 2.0 grant types and why Authorization Code with PKCE is required for public and SPA clients.
  • What is OpenID Connect (OIDC) and how does it add an identity layer on top of OAuth 2.0?
  • Compare Multi-Factor Authentication (MFA) mechanisms: SMS versus TOTP apps versus FIDO2/WebAuthn hardware keys.
  • Compare Role-Based Access Control (RBAC) and Attribute-Based Access Control (ABAC) in enterprise applications.
  • What is the Principle of Least Privilege (PoLP) and how does Just-in-Time (JIT) access enforcement work?
  • Explain the Cloud Shared Responsibility Model across IaaS, PaaS, and SaaS deployment models.
  • How do you automate Infrastructure as Code (IaC) security scanning using Checkov, tfsec, and Trivy?
  • What container security best practices prevent container breakout attacks (minimal images, rootless mode)?
  • How do pre-commit hooks and tools like GitGuardian and TruffleHog prevent API keys from leaking into Git?
  • How does a Web Application Firewall (WAF) inspect HTTP traffic to block common web attacks?
  • Compare Intrusion Detection Systems (IDS) and Intrusion Prevention Systems (IPS) in network defense.
  • Explain the Common Vulnerability Scoring System (CVSS): Base, Temporal, and Environmental metrics.
  • How do you design a strict Content Security Policy (CSP) without allowing `unsafe-inline` scripts?
  • How do Subresource Integrity (SRI) hashes prevent compromised third-party CDNs from injecting malware?
  • What is HTTP Strict Transport Security (HSTS) and how does the HSTS preload list enforce HTTPS?
  • How do cookie security flags (`HttpOnly`, `Secure`, `SameSite`) protect authentication tokens against theft?
  • How do you secure outgoing and incoming webhooks using HMAC signatures and timestamp replay checks?
  • How do you harden reverse proxies: Disabling version disclosure headers and restricting HTTP methods?
  • How do you harden SSH access: Disabling password authentication, enforcing Ed25519 keys, and using bastions?
  • Compare database Encryption at Rest (TDE), Encryption in Transit (TLS), and Application-Level Field Encryption.
  • How do phishing-resistant MFA credentials (FIDO2/WebAuthn) defeat advanced adversary-in-the-middle phishing?
  • What is Cross-Site WebSocket Hijacking (CSWSH) and how do you protect WebSocket handshakes with origin checks?
  • How do you monitor and alert on impending SSL/TLS certificate expirations to avoid production outages?

Gear 3: Senior (5 to 8 years)

  • How do you threat-model a new feature?
  • A cloud access key was committed to a public repository. What do you do?
  • What is Server-Side Request Forgery (SSRF) and how do attackers exploit cloud metadata endpoints (IMDSv1/v2)?
  • How does Insecure Deserialization lead to Remote Code Execution (RCE) in modern runtimes?
  • What is Interactive Application Security Testing (IAST) and how does it combine SAST and DAST advantages?
  • Explain the STRIDE threat modeling framework: Spoofing, Tampering, Repudiation, Info Disclosure, DoS, Elevation.
  • How do you conduct architectural threat modeling using DREAD and PASTA methodologies?
  • Explain Public Key Infrastructure (PKI): Certificate Authorities (CA), Root Certificates, and CRLs/OCSP.
  • Explain the TLS 1.3 handshake: What cipher suites are supported and how does 0-RTT resumption work?
  • What is Perfect Forward Secrecy (PFS) and how does ephemeral Diffie-Hellman prevent historical decryption?
  • Explain Key Management Services (KMS): Hardware Security Modules (HSM) and Envelope Encryption.
  • How do you design an automated cryptographic key rotation pipeline without service downtime?
  • Explain SAML 2.0 Single Sign-On (SSO): Identity Provider (IdP), Service Provider (SP), and SAML Assertions.
  • What is Privileged Access Management (PAM) and how do Bastion Hosts secure administrative access?
  • How do AWS IAM policy evaluation mechanics work: Explicit Deny, SCPs, Permission Boundaries, and Role Assumption?
  • What is Cloud Security Posture Management (CSPM) and how does it detect configuration drift?
  • How do Linux seccomp profiles, AppArmor, and dropping capabilities (`cap-drop`) harden Docker containers?
  • Explain Kubernetes Pod Security Standards: Privileged, Baseline, and Restricted security profiles.
  • How do you audit and harden Kubernetes RBAC to prevent excessive ClusterRoleBinding permissions?
  • How do Kubernetes NetworkPolicies enforce default-deny ingress and egress rules between namespaces?
  • How do Admission Controllers (OPA Gatekeeper, Kyverno) enforce security guardrails on Kubernetes manifests?
  • Explain HashiCorp Vault architecture: Storage backends, dynamic secrets, and leasing/revocation lifecycles.
  • How do you mitigate Distributed Denial of Service (DDoS) attacks across Layer 4 (SYN floods) and Layer 7 (HTTP floods)?
  • How do SIEM (Security Information and Event Management) platforms ingest and correlate security logs?
  • What are the core workflows and responsibilities of Tier 1, Tier 2, and Tier 3 SOC analysts?
  • Explain the NIST Incident Response lifecycle: Preparation, Detection, Containment, Eradication, and Recovery.
  • Compare Red Team, Blue Team, and Purple Team security exercises in evaluating organizational resilience.
  • How do you establish and manage a Bug Bounty program and Coordinated Vulnerability Disclosure (CVD) policy?
  • Overview of SOC 2 Type II, ISO 27001, and PCI-DSS compliance frameworks for enterprise software.
  • What is DNSSEC and how does public-key cryptography prevent DNS spoofing and cache poisoning?
  • What is SSL/TLS Certificate Pinning in mobile applications, and what operational risks does it introduce?
  • How do you prevent Mass Assignment and Broken Function-Level Authorization in RESTful APIs?
  • Design a secure file upload architecture featuring antivirus scanning, MIME validation, and S3 isolation.
  • How do you prevent GraphQL Denial of Service attacks using query depth limiting and query cost analysis?
  • How do AWS CloudTrail and GCP Cloud Audit Logs provide tamper-evident security audit trails?
  • How does AWS GuardDuty use machine learning and threat intelligence to detect account compromises?
  • How do you secure CI/CD build environments against software supply chain attacks and poisoned pipelines?
  • Compare traditional VPN architectures with Zero Trust Network Access (ZTNA) and BeyondCorp models.
  • How do Data Loss Prevention (DLP) engines scan and redact sensitive PII and payment data in transit?
  • How do immutable backups and air-gapped storage protect organizations against ransomware extortion?
  • What is a TPM (Trusted Platform Module) and how does Secure Boot verify kernel integrity during boot?
  • Explain memory safety vulnerabilities (buffer overflow, use-after-free) and the role of memory-safe languages.
  • What are timing attacks in cryptographic operations, and how do constant-time string comparisons prevent them?
  • Explain OAuth 2.0 Token Revocation (RFC 7009) and Token Introspection (RFC 7662) architectures.
  • What is Prototype Pollution in JavaScript and how do attackers pollute the Object prototype to hijack logic?
  • How do you tune Linux kernel parameters via `sysctl` to harden network stacks against SYN flood attacks?
  • What are common AWS IAM privilege escalation paths and how do you audit permissions using IAM Access Analyzer?
  • What are the primary phases of a professional penetration test: Scoping, Recon, Exploitation, and Reporting?
  • What is digital forensics and how do you preserve volatile memory and disk artifacts following an intrusion?
  • How do Canary Tokens and Honeytokens alert security teams when unauthorized actors access sensitive data?
  • How do security teams respond to zero-day vulnerabilities using virtual patching at the WAF layer?
  • What security considerations apply when designing serverless functions (AWS Lambda, Cloud Functions)?
  • How do you secure database and cache instances: Enforcing TLS, VPC endpoints, and disabling default ports?
  • What defenses prevent automated Credential Stuffing and Account Takeover (ATO) attacks on login portals?

Gear 4: Lead / Staff (8+ years)

  • How would you build an application security program for a 200-engineer company?
  • What is Zero Trust Architecture (ZTA) and how do microsegmentation and continuous verification enforce it?
  • Explain the SLSA (Supply-chain Levels for Software Artifacts) framework and Software Bill of Materials (SBOM).
  • How does mutual TLS (mTLS) with SPIFFE/SPIRE provide verifiable service identities in microservices?
  • What causes container escape vulnerabilities and how do User Namespaces prevent root in container from being root on host?
  • How would you design a workforce identity architecture with single sign-on, strong authentication and conditional access?
  • How do you design a secrets and encryption key management strategy across multiple clouds and teams?
  • How do you build a detection engineering and threat hunting capability in a security operations team?
  • How do you quantify and report cyber risk to the board and executives in business terms?
  • How do you design a data security architecture covering classification, encryption, tokenisation and data loss prevention?
  • How do you secure a multi-tenant SaaS platform and guarantee tenant isolation?
  • How do you run vulnerability management at scale so teams fix what matters first?
  • How do you build resilience against ransomware, from prevention to recovery?
  • How do you build a security programme for AI and LLM applications, including threat modelling and controls?
  • How do you lead the response to a major data breach, including forensics, legal obligations and communications?
