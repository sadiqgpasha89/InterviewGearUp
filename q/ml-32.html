Explain Convolutional Neural Networks (CNN): Kernels, Strides, Padding, and Feature Maps.

ML / AI engineer · Gear 2 (Mid-level) · Deep Learning · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

A CNN slides small learnable kernels (filters) across an image, computing dot products to produce feature maps that detect patterns such as edges. Stride is the step size, padding adds border pixels to control output size, and the output size is floor((W - K + 2P) / S) + 1. Weight sharing and local connectivity make CNNs far more parameter-efficient than fully connected layers for images.

Explained in depth

Core pieces

  • Kernel (filter): a small weight tensor, such as 3x3xC_in. It is moved across the input; at each position it computes a dot product, adding a bias.
  • Feature map: the grid of outputs from one kernel. A layer with 64 kernels produces 64 feature maps (channels).
  • Stride (S): how many pixels the kernel moves each step. A stride of 2 halves the spatial size.
  • Padding (P): extra border (usually zeros). "Same" padding keeps the size; "valid" uses none.

Output size

out = floor((W - K + 2P) / S) + 1 Example: input 32, kernel 3, padding 1, stride 1 gives 32; with stride 2 it gives 16.

Parameters

A conv layer has K * K * C_in * C_out + C_out parameters. For 3x3, 64 input and 128 output channels: 3*3*64*128 + 128 = 73,856. This does not depend on the image size, because the weights are shared across positions.

Why CNNs work for images

  • Local connectivity: each output depends on a small neighbourhood.
  • Weight sharing gives translation equivariance: the same detector works anywhere.
  • Hierarchy: early layers detect edges and textures; deeper ones combine them into parts and objects. The receptive field grows with depth, with pooling and strides.
  • Typical blocks: conv, normalisation, activation, optional pooling, finishing with global pooling and a classifier.

Related ideas

1x1 convolutions mix channels cheaply, dilated convolutions widen the receptive field, depthwise separable convolutions reduce computation, and transposed convolutions upsample.
