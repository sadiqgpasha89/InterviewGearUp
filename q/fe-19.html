What is the difference between Shallow Copy and Deep Copy, and how does `structuredClone()` work?

Frontend engineer · Gear 2 (Mid-level) · JavaScript · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

A shallow copy duplicates only the top level, so nested objects are still shared with the original; a deep copy duplicates everything recursively. structuredClone() makes a deep copy using the structured clone algorithm and handles Dates, Maps, Sets, typed arrays and circular references, but it cannot clone functions, DOM nodes or class instances' methods.

Explained in depth

Shallow copies

const a = { name: 'Ana', tags: ['x'] };
const b = { ...a };          // or Object.assign({}, a), or arr.slice()
b.name = 'Bo';               // a.name unchanged
b.tags.push('y');            // a.tags is ['x', 'y'], the array is shared

Deep copies

const c = structuredClone(a);
c.tags.push('z');            // a.tags is unaffected

What structuredClone supports

  • Primitives, plain objects and arrays, Date, RegExp, Map, Set, ArrayBuffer and typed arrays, Error objects, and circular references.
  • It can transfer ownership of buffers cheaply with the second argument.

What it cannot do

  • Functions and methods throw a DataCloneError.
  • DOM nodes cannot be cloned.
  • Class instances lose their prototype: the clone is a plain object with the same own data properties.
  • Property descriptors, getters and setters are not preserved.

The JSON trick and why to avoid it

JSON.parse(JSON.stringify(x)) turns Date into strings, drops undefined and functions, fails on circular references, turns NaN into null and loses Map and Set.

Alternatives

Libraries such as lodash's cloneDeep, or immutable updates that copy only the changed path, which is cheaper than copying everything.
