Gear 1: Junior (0 to 2 years)

  • What is the test pyramid?
  • What is the difference between severity and priority? What makes a good bug report?
  • Explain the Test Automation Pyramid and the recommended balance between Unit, Integration, and E2E tests.
  • Compare Black-Box, White-Box, and Gray-Box testing methodologies with concrete examples.
  • How do you perform Boundary Value Analysis (BVA) and Equivalence Partitioning on input fields?
  • Differentiate between Smoke testing, Sanity testing, and Full Regression testing suites.
  • Explain the difference between Defect Severity and Defect Priority with illustrative examples.
  • Walk through the complete defect lifecycle from discovery and triage to verification and closure.
  • What makes a high-quality, reproducible bug report that accelerates developer remediation?
  • How do you validate client-side input validations, regex patterns, and error messaging effectively?
  • What are the levels of software testing: unit, integration, system and acceptance testing?
  • What is the difference between verification and validation, and between QA, QC and testing?
  • What is the difference between functional and non-functional testing? Give examples of each.
  • How would you write test cases for a login page, covering positive, negative and edge scenarios?
  • What is the software testing life cycle (STLC), and how does it fit with the development life cycle?

Gear 2: Mid-level (2 to 5 years)

  • Your automated UI tests are flaky. How do you fix that?
  • Design test cases for an age field that accepts 18 to 60. How would you test a login page?
  • How does Decision Table testing help model complex business logic and combinatorial rules?
  • What is State Transition Testing and how do you design tests for dynamic order or account lifecycles?
  • What is Exploratory Testing, and how do you structure session-based test charters for team exploratory runs?
  • Explain the Page Object Model (POM) design pattern in UI automation and how it promotes maintenance.
  • Compare locator strategies: CSS selectors, XPath, and `data-testid` attributes for test stability.
  • How do you handle asynchronous UI state updates: Explicit Waits vs Fluent Waits vs Thread.sleep?
  • How do you design a cross-browser automated testing framework supporting Chrome, Firefox, and Safari?
  • What is Visual Regression testing and how do pixel-by-pixel comparisons differ from DOM snapshot checks?
  • Compare Selenium WebDriver, Playwright, and Cypress: Execution architecture, speed, and limitations.
  • How do you structure an API test automation framework using REST Assured or pytest-requests?
  • How do you validate JSON Schemas (Draft-07, Draft-2020-12) automatically within API regression suites?
  • How do you use WireMock or Mockoon to stub third-party payment and identity APIs in integration tests?
  • How do you write automated tests to verify API idempotency, network timeouts, and HTTP 429 rate limits?
  • How do you automate testing of OAuth 2.0 and JWT token authentication, refreshes, and expirations?
  • Explain performance testing categories: Load, Stress, Soak, Spike, and Breakpoint testing.
  • What are the key performance testing metrics: Throughput (TPS/RPS), Latency percentiles (P95, P99), and Error rate?
  • Compare performance testing tools: k6 versus Apache JMeter versus Gatling versus Locust.
  • How do you manage test data generation to ensure deterministic, isolated, and repeatable test runs?
  • How do you manage test database state: Seeding, transactional rollbacks, and teardowns between tests?
  • How do you generate comprehensive test execution reports with screenshots and videos using Allure Framework?
  • Compare code coverage metrics: Line coverage versus Branch coverage versus Mutation score.
  • How do you automate accessibility (a11y) testing in CI pipelines using axe-core and Pa11y?
  • How do QA engineers integrate automated basic security tests (SQLi, XSS, auth bypass) into CI suites?
  • What is Shift-Left Testing and how does introducing QA early in requirements prevent defect leakage?
  • How do you automate testing of file uploads, drag-and-drop, and multipart form submissions?
  • How do you automate testing for real-time WebSocket communication and bidirectional message streams?
  • How do you bypass or handle CAPTCHA and Two-Factor Authentication (2FA) in automated regression suites?
  • How do you perform test impact analysis to select only relevant regression tests following code changes?
  • How do you automate responsive web design verification across desktop, tablet, and mobile viewport sizes?
  • How do you verify client-side storage states (LocalStorage, SessionStorage, Cookies) during automated tests?
  • How do you test GraphQL APIs: Automating query validation, mutations, and error response checks?
  • How do you design a fast, high-confidence smoke test suite that gates pull requests and deployments?
  • How do you automate verification of transactional email delivery using tools like MailHog or Inbucket?
  • How do you test Progressive Web App (PWA) offline caching behavior and service worker lifecycles?
  • How do you verify file downloads (PDF, CSV, Excel) and validate their contents in automated browser tests?
  • How do you test internationalization (i18n), right-to-left (RTL) layouts, and locale date formats?
  • How do you calculate the Return on Investment (ROI) of test automation initiatives for leadership?
  • How do you test cookie consent banners and verify that tracking scripts are blocked before consent?
  • How do you automate interaction with dynamic iframes, shadow DOM elements, and multi-window popups?
  • How do you test asynchronous background email and SMS dispatching queues in staging?
  • How do you test Single Page Applications (SPA) with client-side routing to avoid stale element references?
  • How do you verify that HTTP caching headers (`Cache-Control`, `ETag`) are correctly honored by browsers and CDNs?
  • How do you verify database transaction rollback behavior during unexpected application errors?
  • How do you use Docker Compose to spin up local integration testing environments for developers?
  • What is Behavior-Driven Development (BDD) and how do Gherkin Given-When-Then scenarios connect to test code?
  • What are the common pitfalls of BDD adoption, and when does Cucumber add unnecessary maintenance overhead?
  • How do you verify Cross-Origin Resource Sharing (CORS) configurations in automated API tests?
  • How do you test infinite scroll lists and virtualized DOM components without missing scrolled elements?
  • How do you test application behavior under simulated geolocation shifts and device time zone changes?
  • How do you design a smoke testing suite for Continuous Deployment (CD) that gates production rollouts?
  • How do you automate interactions with native OS file dialogs and authentication popups in Playwright?
  • How do you build self-cleaning test fixtures that prevent test database pollution during parallel runs?

Gear 3: Senior (5 to 8 years)

  • What is your test strategy for a payments microservice?
  • Compare the Screenplay Pattern with Page Object Model: Actors, Tasks, and Question abstractions.
  • Explain the Appium architecture and how it automates native and hybrid iOS and Android applications.
  • How does Playwright auto-waiting and network interception architecture eliminate flaky test timing?
  • Explain Cypress in-browser execution architecture and its constraints regarding multiple tabs and origins.
  • What is Consumer-Driven Contract Testing and how does Pact verify microservice contract compatibility?
  • How do you diagnose performance bottlenecks: Database connection pool exhaustion, memory leaks, and CPU locks?
  • How does Testcontainers spin up ephemeral databases, message brokers, and Redis instances during test runs?
  • What are the common root causes of flaky tests, and what strategies (quarantine, retries) mitigate them?
  • How do you implement test suite sharding and parallel execution in GitHub Actions or GitLab CI?
  • What is Mutation Testing (Stryker, Pitest) and how does it evaluate the quality of an automated test suite?
  • How do you test asynchronous event-driven architectures involving Apache Kafka or RabbitMQ consumers?
  • What is Shift-Right Testing and how do synthetic canary monitoring and testing in production work safely?
  • How do you test microservice workflows using distributed tracing headers (W3C Trace Context)?
  • How do you test zero-downtime database migrations to ensure backward compatibility with older app versions?
  • How do you design an automated test suite for payment gateway flows (Stripe/PayPal) with mock webhooks?
  • How do you load test a WebSocket server sustaining 50,000 concurrent connected users?
  • How do you build an automated flaky test detector that quarantines unstable tests automatically?
  • How do you automate mobile deep link testing and push notification receipt on iOS and Android?
  • What is service virtualization and how does it allow testing against simulated external partners?
  • How do you test for Broken Object-Level Authorization (BOLA/IDOR) in automated API suites?
  • How do you introduce an automated testing safety net to a legacy application with zero test coverage?
  • How do you automate testing for Single Sign-On (SSO) SAML and OIDC enterprise login flows?
  • How do you load test gRPC microservices utilizing Protocol Buffers serialization?
  • How do you automate data pipeline testing: Validating row counts, schema consistency, and data drift?
  • How do you inject Chaos Engineering faults (network latency, service drops) during integration testing?
  • How do you detect performance regressions automatically by tracking benchmark metrics across git commits?
  • Design a scalable test automation framework from scratch: Directory layout, utilities, and runners.
  • How do you configure an Appium test grid to run mobile tests in parallel across physical and virtual devices?
  • How do you test microservice resilience patterns like circuit breakers and fallbacks under failure conditions?
  • How do you test outgoing webhooks: Verifying HMAC cryptographic signatures and delivery retry backoff?
  • How do you test large-scale batch ETL pipelines with deterministic synthetic data fixtures?
  • How do you integrate OWASP ZAP into automated CI/CD security regression test suites?
  • How do you test video streaming player performance: HLS/DASH manifest loading, buffer lag, and bitrates?
  • How do you test service degradation under simulated low disk space and memory pressure?

Gear 4: Lead / Staff (8+ years)

  • Your team ships weekly but quality is inconsistent. What quality strategy would you build?
  • How do you measure and reduce test flakiness across an organization with hundreds of pipelines?
  • How do contract testing and testing in production complement end-to-end tests in a microservices architecture?
  • How would you move an organisation from mostly manual testing to an automation-first quality engineering model?
  • How do you design a test environment strategy with ephemeral environments, realistic data and production parity?
  • How do you set up a quality metrics programme that drives decisions instead of vanity numbers?
  • How do you structure a quality organisation: embedded SDETs, a central QA team, or developers owning testing?
  • How would you design test infrastructure to run 100,000 tests a day reliably and cost-effectively?
  • How do you plan quality assurance for a major re-platforming or migration project without regressions?
  • How do you build a risk-based testing and release readiness framework for an organisation?
  • How do you test features powered by machine learning or LLMs, where outputs are non-deterministic?
  • What testing strategy would you design for a microservices platform with hundreds of services that deploy independently?
  • How do you build a culture where developers take ownership of quality instead of relying on QA?
  • How do you build a performance engineering practice across an organisation, from SLOs to capacity planning?
  • How do you learn from production incidents to close test and process gaps, and prevent repeat escapes?
