How do Decision Trees choose splits using Gini Impurity versus Entropy and Information Gain?

ML / AI engineer · Gear 1 (Junior) · Tree Models · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

A decision tree picks, at each node, the split that makes the child nodes as pure as possible. Gini impurity is 1 minus the sum of squared class proportions; entropy is the negative sum of p log p. Information gain is the parent's entropy minus the weighted entropy of the children. Gini and entropy usually pick very similar splits, and Gini is slightly cheaper to compute.

Explained in depth

Impurity measures

With class proportions p_k at a node:

  • Gini = 1 - sum(p_k^2). It is 0 for a pure node and 0.5 for a 50/50 binary node.
  • Entropy = - sum(p_k * log2(p_k)). It is 0 for pure and 1 bit for 50/50.

Information gain

Gain = Impurity(parent) - sum( (n_child / n_parent) * Impurity(child) ) The tree evaluates candidate splits (for each feature, each threshold between sorted values) and chooses the one with the highest gain, or the largest drop in weighted Gini. It then repeats recursively on each child.

Example

Parent has 10 samples, 5 positive and 5 negative: Gini = 0.5. A split sends (4 positive, 1 negative) left and (1 positive, 4 negative) right. Each child has Gini = 1 - (0.8^2 + 0.2^2) = 0.32, so the weighted Gini is 0.32 and the gain is 0.18.

Gini versus entropy

In practice they give almost the same trees. Gini is a little faster (no logarithm); entropy penalises mixed nodes slightly more. Information gain with raw entropy favours features with many distinct values, which is why C4.5 uses gain ratio.

Controlling overfitting

Unlimited trees memorise the training data. Use max_depth, min_samples_leaf, min_impurity_decrease or cost-complexity pruning. Ensembles (random forests, gradient boosting) combine many trees to reduce variance.
