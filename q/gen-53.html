How do you find the single non-duplicate number in an array where every other element appears twice?

Software engineer (core) · Gear 2 (Mid-level) · Bit manipulation · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

XOR all the elements. Because x ^ x = 0 and x ^ 0 = x, every value that appears twice cancels out and only the single non-duplicate remains. It runs in O(n) time and O(1) extra space, with no hash map and no sorting.

Explained in depth

Core idea

XOR has three properties that make this problem trivial:

  • a ^ a = 0 (a value cancels itself)
  • a ^ 0 = a (zero is the identity)
  • it is commutative and associative, so order does not matter
def single_number(nums):
    acc = 0
    for x in nums:
        acc ^= x
    return acc

Every duplicated pair collapses to zero, leaving the unique value. Time O(n), extra space O(1).

Extension 1: two unique numbers

If two values a and b appear once and all others twice, the total XOR is x = a ^ b, which is non-zero. Pick any set bit of x (for example low = x & -x). a and b differ at that bit, so split the numbers by whether that bit is set and XOR each group separately. Each group contains one unique value plus pairs, so the two results are a and b.

Extension 2: every other value appears three times

XOR cancels pairs only. Count bits instead: for each bit position, sum that bit over all numbers and take the sum modulo 3. The remaining bits form the unique number. A branch-free version keeps two accumulators ones and twos:

ones = twos = 0
for x in nums:
    ones = (ones ^ x) & ~twos
    twos = (twos ^ x) & ~ones
return ones

Edge cases and pitfalls

  • The technique assumes the stated guarantee (every other value appears exactly twice). With other multiplicities the XOR answer is meaningless, so validate the input contract.
  • Negative numbers work in Python and Java because XOR works on two's complement bits.
  • An empty array has no answer; decide whether to raise or return a sentinel.
