Gear 1: Junior (0 to 2 years)

  • What makes an API RESTful? Explain HTTP methods, status codes and idempotency.
  • What is the difference between INNER JOIN and LEFT JOIN?
  • How do parameterized queries prevent SQL injection compared to dynamic string concatenation?
  • What is the difference between SQL and NoSQL databases, and how do you choose between them?
  • What is a database index and what does it cost?
  • What is the difference between PUT, PATCH and POST in a REST API?
  • How do HTTP status codes and error responses help clients handle failures, and which ones should an API use?
  • What is the N+1 query problem and how do you fix it?
  • What is a message queue and why would you use one in a backend system?
  • What is dependency injection and why is it useful in backend code?
  • What is the difference between blocking and non-blocking I/O, and between synchronous and asynchronous code?
  • What are primary keys, foreign keys and constraints, and why do they matter?
  • What is database connection pooling and why is it important?
  • What is HTTP caching and how do Cache-Control and ETag headers work?
  • What is middleware in a web framework, and what are typical uses?

Gear 2: Mid-level (2 to 5 years)

  • Explain ACID and transaction isolation levels. What anomalies can occur?
  • Describe caching strategies and how you deal with invalidation and cache stampedes.
  • What is the difference between authentication and authorization? Sessions versus JWTs?
  • How do GraphQL and REST compare, and how do you resolve the GraphQL N+1 problem?
  • What are the advantages of gRPC over REST with JSON, and when should you choose each?
  • Compare WebSockets, Server-Sent Events (SSE), and Long Polling for real-time communication.
  • How does a B+ Tree index work in relational databases, and why is it preferred over a binary tree?
  • What is index selectivity and cardinality, and how do they determine whether the query planner uses an index?
  • Explain the leftmost prefix rule for composite indexes. When will an index on (A, B, C) be used?
  • What is database replication lag, and how do you ensure read-your-own-writes consistency?
  • How does connection pooling work, and how do you size a pool like HikariCP or PgBouncer?
  • What are the normal forms (1NF, 2NF, 3NF) and when is denormalization preferred?
  • Compare Redis data structures: Hashes, Sets, Sorted Sets, and Bitmaps with practical use cases.
  • Explain Cache-Aside, Read-Through, Write-Through, and Write-Behind caching patterns.
  • How do cache eviction policies like LRU, LFU, FIFO, and TTL differ under memory pressure?
  • What is a cache avalanche and why should cache expiration TTLs include random jitter?
  • Compare RabbitMQ exchange types: Direct, Fanout, Topic, and Headers.
  • How do you design a resilient Dead Letter Queue (DLQ) with exponential backoff and retry limits?
  • What is the difference between OS threads, processes, and lightweight green threads or goroutines?
  • Compare JSON Web Tokens (JWT) and opaque server-side session cookies for stateless authentication.
  • Compare Token Bucket and Leaky Bucket algorithms for API rate limiting.
  • How does a sliding window log rate limiter compare to a sliding window counter approximation?
  • What is Cross-Origin Resource Sharing (CORS), and what triggers an HTTP OPTIONS preflight request?
  • How do presigned S3/GCS URLs allow clients to upload large files directly without overwhelming backend servers?
  • What is the difference between Kubernetes liveness probes and readiness probes in backend services?
  • How do you implement graceful shutdown in a web server upon receiving a SIGTERM signal?
  • How do you read a database EXPLAIN ANALYZE output and distinguish index scans from sequential scans?
  • What are the trade-offs of enforcing foreign keys at the database level versus the application service layer?
  • When should you model one-to-many relationships as embedded documents versus referenced IDs in MongoDB?
  • Compare Redis RDB point-in-time snapshots with Append-Only File (AOF) persistence modes.
  • How do atomic Redis INCR and DECR commands enable distributed counters and inventory decrement?
  • How do background task queues (e.g., Celery, BullMQ) handle task retries, timeouts, and state tracking?
  • What is the difference between Point-to-Point message queues and Publish-Subscribe topic patterns?
  • What are the pros and cons of URI path versioning versus header versioning for REST APIs?
  • Why is keyset (cursor-based) pagination preferred over offset/limit pagination for large datasets?
  • What are the architectural trade-offs of soft delete flags (`is_deleted`) versus hard deletes with audit tables?
  • How does contract-first API development using OpenAPI/Swagger improve client-server consistency?
  • Compare Memcached multithreaded architecture with Redis single-threaded event loop architecture.

Gear 3: Senior (5 to 8 years)

  • Explain the CAP theorem and how it affects your choice of database.
  • Design a payment API so that retries never charge a customer twice.
  • A database query is slow in production. How do you investigate and fix it?
  • How does database sharding work, and what are the trade-offs between range-based and hash-based sharding?
  • Compare optimistic locking and pessimistic locking. When should each be applied?
  • How do relational databases detect and resolve deadlocks, and how can applications prevent them?
  • Explain PostgreSQL MVCC internals, tuple bloat, and the necessity of VACUUM.
  • What is Write-Ahead Logging (WAL) and how does it guarantee durability and crash recovery?
  • How do you execute zero-downtime database schema migrations using the expand-contract pattern?
  • What is a cache stampede (thundering herd) and how do single-flight locks and XFetch prevent it?
  • Explain cache penetration and how Bloom filters prevent querying non-existent keys in the database.
  • How does Apache Kafka partition topics, and how are strict message ordering guarantees maintained?
  • Explain Kafka consumer groups, offset commits, and the partition rebalance protocol.
  • What is Kafka log compaction and how does it support stateful stream processing?
  • How do you implement backpressure and consumer rate limiting in asynchronous message queues?
  • How does service discovery work in microservices using client-side vs. server-side approaches?
  • What are the responsibilities of an API Gateway, and how does it differ from a Reverse Proxy?
  • How does the Circuit Breaker pattern transition between Closed, Open, and Half-Open states?
  • Explain the Bulkhead pattern and how thread pool isolation prevents cascading service outages.
  • How do distributed tracing systems correlate requests across microservices using W3C Trace Context?
  • What is the Transactional Outbox pattern, and how does Change Data Capture (CDC) ensure reliability?
  • What is Command Query Responsibility Segregation (CQRS) and what trade-offs does it introduce?
  • How does consistent hashing with virtual nodes prevent data skew and re-hashing overhead?
  • Explain the trade-offs of the CAP theorem: When should a distributed system choose CP versus AP?
  • Compare distributed locking mechanisms: Redis Redlock versus ZooKeeper/etcd sequential ephemeral nodes.
  • How do you calculate optimal thread pool size for CPU-bound versus I/O-bound workloads?
  • How does non-blocking asynchronous I/O (epoll/kqueue) enable high concurrency in event-driven runtimes?
  • How do you diagnose and resolve a memory leak in a production backend service using heap dumps?
  • How do you profile a CPU-bound backend microservice and interpret flame graphs to locate hotspots?
  • How does OAuth 2.0 Authorization Code Flow with PKCE protect against authorization code interception?
  • What is the difference between Role-Based Access Control (RBAC) and Attribute-Based Access Control (ABAC)?
  • How do idempotency keys guarantee that network retries do not cause duplicate financial charges?
  • Design a distributed task scheduler that executes millions of scheduled cron tasks with high availability.
  • How do you build a resilient webhook ingestion pipeline that handles duplicate events and bursts?
  • Compare Blue-Green deployments with Canary deployments for zero-downtime microservice upgrades.
  • What are unlogged tables in relational databases, and what are the trade-offs of using them?
  • How does Apache Cassandra use LSM trees, SSTables, and tunable consistency quorums?
  • How do partition keys and sort keys dictate data distribution and query performance in Amazon DynamoDB?
  • How does Redis Cluster shard data across 16,384 hash slots, and how are node failovers handled?
  • What is backpressure in reactive streams, and what strategies exist when producers outpace consumers?
  • How do temporal tables and bi-temporal modeling track historical entity states over time?
  • How do distributed unique ID generators like Twitter Snowflake generate 64-bit sortable IDs?
  • How do you execute atomic rate limiting scripts in Redis using Lua to prevent race conditions?
  • Design a notification service that fans out push notifications, SMS, and emails to millions of users.
  • How does the Strangler Fig pattern allow incrementally decomposing a legacy monolith into microservices?
  • How do message consumers achieve idempotency when message brokers only guarantee at-least-once delivery?
  • How does database partition pruning optimize query performance on partitioned tables?
  • Design a highly available, globally distributed URL shortener service handling 100k writes/sec.

Gear 4: Lead / Staff (8+ years)

  • How would you migrate a monolith to microservices?
  • How does Kafka achieve exactly-once semantics (EOS) across producer and consumer streams?
  • How does the Two-Phase Commit (2PC) protocol work, and why does it fail under coordinator partitions?
  • Explain the Saga pattern for distributed transactions: Choreography versus Orchestration.
  • Explain Event Sourcing. How are current entity states reconstructed from append-only event logs?
  • What is the PACELC theorem and how does it expand upon the CAP theorem during normal operation?
  • How does the Raft consensus algorithm elect leaders and guarantee replicated log consistency?
  • Explain garbage collection pause phases in modern runtimes (e.g. G1GC, ZGC, Go GC) and how to tune them.
  • How does mutual TLS (mTLS) provide service-to-service authentication and encryption in a zero-trust mesh?
  • How does clock skew affect distributed systems, and how do TrueTime and logical clocks address it?
  • Compare multi-tenant database designs: Shared Database/Shared Schema versus Isolated Schemas versus Isolated Databases.
  • Design an idempotent payment processing service that never charges a customer twice.
  • How do you design a backend to degrade gracefully and shed load when it is overloaded?
  • How would you design an audit logging system that is tamper-evident, searchable and compliant?
  • How would you lead a migration from a single large PostgreSQL database to a sharded architecture?
