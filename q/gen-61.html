How do you implement an LRU (Least Recently Used) cache in $O(1)$ time using a Hash Map and Doubly Linked List?

Software engineer (core) · Gear 3 (Senior) · Data structures · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

Combine a hash map from key to node with a doubly linked list ordered by recency. get moves the node to the front, put inserts at the front and evicts the tail when over capacity. Every step is a pointer change or a map lookup, so both operations are O(1).

Explained in depth

Why this pair

  • The hash map finds a node in O(1).
  • The doubly linked list can remove a node in O(1) given the node, because it knows both neighbours, and can add at the head in O(1). A singly linked list cannot unlink a middle node without its predecessor.
  • Keep sentinel head and tail nodes so you never special-case an empty list.
class LRU {
  constructor(cap) {
    this.cap = cap; this.map = new Map();
    this.head = {}; this.tail = {};          // sentinels
    this.head.next = this.tail; this.tail.prev = this.head;
  }
  _remove(n) { n.prev.next = n.next; n.next.prev = n.prev; }
  _addFront(n) { n.next = this.head.next; n.prev = this.head; this.head.next.prev = n; this.head.next = n; }
  get(key) {
    const n = this.map.get(key);
    if (!n) return -1;
    this._remove(n); this._addFront(n);       // now most recent
    return n.val;
  }
  put(key, val) {
    let n = this.map.get(key);
    if (n) { n.val = val; this._remove(n); this._addFront(n); return; }
    if (this.map.size === this.cap) {
      const lru = this.tail.prev;             // least recent
      this._remove(lru); this.map.delete(lru.key);
    }
    n = { key, val }; this.map.set(key, n); this._addFront(n);
  }
}

Notes

  • Store the key in the node so eviction can remove the map entry.
  • Language shortcuts: JavaScript's Map keeps insertion order (delete and re-set to refresh), Python has OrderedDict, and Java's LinkedHashMap supports access order. Interviews usually want the manual version.
  • In concurrent code you need a lock or a sharded design, because get also mutates the list.
