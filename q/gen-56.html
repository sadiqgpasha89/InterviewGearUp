How does the Master Theorem solve divide-and-conquer recurrence relations like $T(N) = aT(N/b) + f(N)$?

Software engineer (core) · Gear 2 (Mid-level) · Complexity · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

The Master Theorem solves T(n) = aT(n/b) + f(n) by comparing f(n) with n^(log_b a), the work at the leaves. If f is polynomially smaller the leaves dominate, if equal each level contributes equally (extra log factor), and if larger the root dominates, provided a regularity condition holds.

Explained in depth

Setup

A divide and conquer algorithm splits a problem of size n into a subproblems of size n/b, then spends f(n) on dividing and combining. The recursion tree has depth log_b n and a^(log_b n) = n^(log_b a) leaves. Define the critical exponent c* = log_b a. Everything depends on how f(n) compares with n^c*.

The three cases

CaseConditionResult
1: leaves dominatef(n) = O(n^(c* - e)) for some e > 0T(n) = Theta(n^c*)
2: balancedf(n) = Theta(n^c* * log^k n), k >= 0T(n) = Theta(n^c* * log^(k+1) n)
3: root dominatesf(n) = Omega(n^(c* + e)) and a f(n/b) <= c f(n) for some c < 1T(n) = Theta(f(n))

The extra condition in case 3 is called the regularity condition; it ensures work shrinks geometrically down the tree.

Worked examples

  • Merge sort: T(n) = 2T(n/2) + n. Here a = 2, b = 2, c* = 1, f(n) = n = Theta(n^1), so case 2 with k = 0: Theta(n log n).
  • Binary search: T(n) = T(n/2) + 1. c* = 0, f(n) = 1 = Theta(n^0), case 2: Theta(log n).
  • Karatsuba multiplication: T(n) = 3T(n/2) + n. c* = log_2 3 ~ 1.585, f is smaller, case 1: Theta(n^1.585).
  • Strassen: T(n) = 7T(n/2) + n^2, c* ~ 2.807, case 1: Theta(n^2.807).
  • Quickselect (balanced): T(n) = T(n/2) + n, c* = 0, f larger and regular, case 3: Theta(n).

When it does not apply

  • Gaps between cases: T(n) = 2T(n/2) + n / log n or n log n with the wrong polynomial gap. (The extended case 2 handles n log^k n, k >= 0, but not negative k.)
  • Unequal subproblem sizes: T(n) = T(n/3) + T(2n/3) + n (use the Akra-Bazzi method or a recursion tree).
  • Non-constant a, subtraction instead of division (T(n) = T(n-1) + n, which is Theta(n^2) by unrolling), or f(n) that is not polynomial.

Practical method

Draw the recursion tree: the level i cost is a^i * f(n / b^i). Sum over log_b n levels. The cases correspond to that sum being dominated by the last level, equal on every level, or dominated by the first level.

Pitfalls

Using the theorem when f(n) is only asymptotically close to n^c* (not polynomially different), forgetting the regularity check in case 3, and forgetting that b can be a non-integer.

Likely follow-ups
