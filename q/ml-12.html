Define Precision, Recall, F1-Score, and Specificity with confusion matrix formulas.

ML / AI engineer · Gear 1 (Junior) · Metrics · Difficulty: easy · AI-drafted, not yet reviewed by a person

In 30 seconds

From the confusion matrix counts TP, FP, FN and TN: precision = TP/(TP+FP), recall = TP/(TP+FN), specificity = TN/(TN+FP) and F1 = 2PR/(P+R), the harmonic mean of precision and recall. Precision asks how many flagged items are right; recall asks how many real positives were found.

Explained in depth

Confusion matrix

Predicted positivePredicted negative
Actual positiveTP (true positive)FN (false negative)
Actual negativeFP (false positive)TN (true negative)

Formulas

  • Precision = TP / (TP + FP): of everything predicted positive, the fraction that is correct.
  • Recall (sensitivity, true positive rate) = TP / (TP + FN): of all actual positives, the fraction found.
  • Specificity (true negative rate) = TN / (TN + FP): of all actual negatives, the fraction correctly rejected.
  • F1 = 2 * Precision * Recall / (Precision + Recall): the harmonic mean, which is low if either is low.
  • Accuracy = (TP + TN) / total.

Example

A fraud detector flags 100 transactions: 80 are fraud (TP = 80, FP = 20). There are 200 frauds in total, so FN = 120. Precision = 0.8, recall = 80/200 = 0.4, F1 = 2 * 0.8 * 0.4 / 1.2 = about 0.53.

Trade-offs

Raising the decision threshold increases precision and lowers recall; lowering it does the reverse. Choose by cost:

  • Cancer screening or fraud: prioritise recall (missing a case is costly).
  • Spam filtering of important mail, or legal alerts: prioritise precision (false alarms are costly).
  • F-beta weights recall (beta above 1) or precision (beta below 1).

Pitfalls

Accuracy misleads with imbalanced classes (99% accuracy by always predicting the majority). Report precision and recall (or PR-AUC), per class, and consider macro or micro averaging for multi-class problems.
