Frontend engineer interview questions

Gear 1: Junior (0 to 2 years)

  • What is a closure in JavaScript?
  • Explain the CSS box model, and when to use Flexbox versus Grid.
  • How does the Critical Rendering Path (CRP) work from HTML parsing to pixel paint?
  • Explain the CSS Box Model: `box-sizing: content-box` versus `border-box`.
  • Explain the difference between `null`, `undefined`, and undeclared variables in JavaScript.
  • What are controlled versus uncontrolled components in React forms, and when is each preferred?
  • What are the security implications of `rel="noopener noreferrer"` on external anchor tags?
  • Explain the difference between `==` loose equality and `===` strict equality, and how `Object.is()` differs.
  • What is the difference between var, let and const in JavaScript, and what is hoisting?
  • How does the this keyword work in JavaScript?
  • What is the virtual DOM, and why do list items need a key prop in React?
  • What is semantic HTML and why does it matter for accessibility and SEO?
  • Explain the CSS position property: static, relative, absolute, fixed and sticky.
  • What is responsive design, and how do media queries and a mobile-first approach work?
  • How do map, filter and reduce work, and why do they avoid mutating arrays?

Gear 2: Mid-level (2 to 5 years)

  • Explain the JavaScript event loop. What is the output order of a script mixing setTimeout and Promises?
  • How does React reconciliation work, and why do list keys matter?
  • A React screen feels slow because of unnecessary re-renders. How do you fix it?
  • What is the difference between Reflow (Layout) and Repaint, and how do you minimize reflows?
  • Explain event bubbling, event capturing, and how event delegation improves performance.
  • What is the Shadow DOM and how does it provide style and DOM encapsulation?
  • Explain JavaScript closures, lexical environments, and practical memory leak risks.
  • How does prototypal inheritance work in JavaScript, and what is the prototype chain?
  • Explain the rules of `this` binding in JavaScript: default, implicit, explicit, and arrow functions.
  • How does the JavaScript Event Loop coordinate the Call Stack, Microtask Queue, and Macrotask Queue?
  • Compare `Promise.all`, `Promise.allSettled`, `Promise.race`, and `Promise.any`.
  • How does `async`/`await` syntactic sugar work under the hood with generators and promises?
  • What is the difference between Shallow Copy and Deep Copy, and how does `structuredClone()` work?
  • Implement and compare debounce and throttle functions with cancellation support.
  • What triggers a Block Formatting Context (BFC) and how does it prevent margin collapse?
  • How is CSS specificity calculated and how does the cascade resolve conflicting declarations?
  • Compare CSS Flexbox and CSS Grid: When is each layout model appropriate?
  • Explain CSS Stacking Contexts and how `z-index` works across parent and child stacking contexts.
  • Compare CSS Modules, CSS-in-JS (Styled Components), and Tailwind utility-first CSS.
  • What are the rules of React Hooks and why must hooks be called at the top level?
  • Compare `useEffect` and `useLayoutEffect`: When does `useLayoutEffect` prevent visual flicker?
  • When should you use `useMemo` and `useCallback`, and what is the cost of premature optimization?
  • How does React `memo` perform shallow prop comparisons, and when does it fail to prevent re-renders?
  • Why can React Context trigger unneeded re-renders across consumers, and how do you optimize it?
  • Compare centralized state management architectures: Redux Toolkit versus Zustand versus Jotai.
  • How do code splitting and dynamic `import()` reduce initial JavaScript bundle size?
  • What is tree shaking and what package configuration (`sideEffects`) is required for bundlers to prune unused code?
  • How do you optimize image delivery using modern formats (AVIF, WebP), responsive `srcset`, and lazy loading?
  • How do Cross-Site Scripting (XSS) attacks occur, and how do modern frameworks protect against them?
  • Explain Cross-Site Request Forgery (CSRF) and how `SameSite=Strict/Lax` cookie attributes mitigate it.
  • What is Clickjacking and how do `X-Frame-Options` and CSP `frame-ancestors` defend against it?
  • How does the browser Same-Origin Policy (SOP) enforce isolation, and how does CORS relax it safely?
  • Compare client-side storage mechanisms: LocalStorage versus SessionStorage versus IndexedDB versus Cookies.
  • How does `IntersectionObserver` enable performant lazy loading and infinite scrolling without scroll listeners?
  • How does `ResizeObserver` observe element dimension changes without triggering infinite layout loops?
  • Explain Web Content Accessibility Guidelines (WCAG) 2.1 AA requirements and semantic HTML usage.
  • How do WAI-ARIA roles, states, and live regions communicate dynamic UI updates to screen readers?
  • How does `requestAnimationFrame` synchronize animations with the browser refresh rate?
  • What is passive event listening (`{ passive: true }`) and why does it improve scroll performance?
  • How do ES Modules (ESM) differ from CommonJS (CJS) in loading semantics and circular dependencies?
  • What is the Temporal Dead Zone (TDZ) for `let` and `const` variables?
  • How does `AbortController` cancel inflight fetch requests and async operations?
  • How do font loading strategies (`font-display: swap/optional`) eliminate Flash of Invisible Text (FOIT)?
  • What is the CSS `content-visibility: auto` property and how does it boost initial render speed?
  • How do you design reusable React compound components using React Context?
  • How does React error boundary catch runtime errors and prevent unmounting the entire component tree?
  • What are React portals (`createPortal`) and why are they used for modal dialogs and tooltips?
  • How does custom hook extraction promote logic reuse without component hierarchy nesting?
  • How do Resource Hints (`preconnect`, `dns-prefetch`, `preload`, `prefetch`) optimize network waterfalls?
  • How do Subresource Integrity (SRI) hashes protect third-party CDN scripts from tampering?
  • How does the Web Clipboard API read and write text and images securely?
  • How does the Page Visibility API allow pausing background video and polling when tabs are inactive?
  • Design an autocomplete search component with debouncing, request cancellation, and keyboard navigation.
  • Design an image carousel component supporting touch gestures, infinite loops, and accessibility.
  • What are the differences between Unit, Component (RTL), and End-to-End (Playwright) testing on the frontend?
  • How do you test asynchronous UI state updates without flaky `sleep` timers in React Testing Library?
  • What is the difference between client-side caching headers: `no-cache` versus `no-store` versus `must-revalidate`?
  • How does Brotli compression compare to Gzip for text assets (HTML, CSS, JS)?
  • What are JavaScript Symbols and how do Well-Known Symbols (`Symbol.iterator`) customize object behavior?
  • How do CSS transitions, animations, and `@keyframes` perform when animating `transform` versus `top/left`?
  • What is the `:has()` relational pseudo-class and how does it replace JavaScript parent selectors?
  • What are synthetic events in React and how do they differ from native browser events?

Gear 3: Senior (5 to 8 years)

  • A page loads slowly on mobile. How do you diagnose and improve it?
  • How do you protect a single-page app from XSS and CSRF, and where should auth tokens be stored?
  • How do WeakMap and WeakSet assist with garbage collection and memory leak prevention?
  • What are CSS Container Queries and how do they differ from viewport Media Queries?
  • How does the React Fiber reconciler break rendering work into incremental units?
  • Explain React 18 Concurrent Features: `useTransition`, `useDeferredValue`, and Suspense.
  • What are React Server Components (RSC) and how do they differ from traditional Server-Side Rendering?
  • How does hydration work in SSR applications, and what causes hydration mismatch errors?
  • How do server-state libraries like TanStack Query (React Query) handle caching, deduplication, and stale data?
  • Explain Core Web Vitals: Largest Contentful Paint (LCP), Interaction to Next Paint (INP), and Cumulative Layout Shift (CLS).
  • How does virtualized list rendering (DOM windowing) enable smooth scrolling over 100,000 items?
  • How do Web Workers offload CPU-intensive computations from the main browser UI thread?
  • How do Service Workers intercept network requests to implement offline-first PWA caching strategies?
  • What is Content Security Policy (CSP) and what directives prevent unauthorized script execution?
  • How does `BroadcastChannel` synchronize application state across multiple browser tabs in real time?
  • How do CSS subgrid and `minmax()` solve nested grid alignment problems?
  • What causes Long Tasks (>50ms) in the browser, and how do you yield to the main thread with `scheduler.yield()`?
  • How do you measure and debug memory leaks in Chrome DevTools using heap snapshots?
  • How does the Navigation Timing and Resource Timing API provide real-user performance monitoring (RUM)?
  • Design a client-side routing library supporting browser history, parameters, and query strings.
  • Design an optimistic UI mutation system with automatic rollback on network failure.
  • How do you build a design system component library with themeable design tokens?
  • How do you implement internationalization (i18n) and RTL layout support in a large web app?
  • Design a multi-step checkout wizard with client-side form validation and draft persistence.
  • What is layout thrashing (forced synchronous layout) and how do batching reads and writes prevent it?
  • How do JavaScript Proxy and Reflect APIs enable reactive state tracking in modern frameworks?
  • How do you implement code splitting at the route level versus component level in React?
  • What is DOM clobbering and how do attackers exploit named HTML elements to overwrite global variables?

Gear 4: Lead / Staff (8+ years)

  • Six teams contribute to one web app. How would you structure the frontend?
  • What is Micro-Frontends architecture and how does Webpack/Vite Module Federation implement it?
  • How would you lead the migration of a large legacy frontend to a new framework without freezing feature work?
  • How do you establish and enforce performance budgets across many frontend teams?
  • How would you design a frontend observability strategy covering errors, performance and user journeys?
  • Design the frontend architecture for a real-time collaborative application such as a whiteboard or document editor.
  • How would you set up a monorepo and build system for 50 frontend engineers working on many apps and shared packages?
  • How do you choose a rendering strategy (CSR, SSR, SSG, streaming, islands) for different parts of a large product?
  • How would you design an offline-first web application with background sync and conflict resolution?
  • How do you build an accessibility program for a large product organisation rather than fixing issues ad hoc?
  • How do you manage dependency and supply chain risk in a large frontend codebase?
  • How do you architect client-side state in a large application, separating server state from client state?
  • How do you roll out a major UI redesign to millions of users safely using flags and experiments?
  • How would you build and run a frontend platform team that improves developer experience for many product teams?
  • How do you define a browser support policy and use progressive enhancement across a large product?
