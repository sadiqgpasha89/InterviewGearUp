How do you handle missing values in a dataset, and how does the missingness mechanism affect your choice?

Data scientist · Gear 1 (Junior) · Data preparation · Difficulty: easy · AI-drafted, not yet reviewed by a person

In 30 seconds

First understand why data are missing: completely at random, at random given other variables, or not at random. Then choose among dropping rows or columns, simple imputation with median or mode plus a missing indicator, model-based or multiple imputation, or tree models that handle missing values natively, always fitting imputers on training data only.

Explained in depth

Step 1: quantify and understand

Measure missingness per column and row (df.isna().mean()), look for patterns (correlation of missingness between columns, missingno matrix), and ask the business why values are missing (optional form field, sensor outage, data pipeline bug, not applicable).

Mechanisms (Rubin):

  • MCAR (missing completely at random): missingness is unrelated to any data; dropping rows is unbiased but wasteful.
  • MAR (missing at random): missingness depends on observed variables (older users skip an optional field). Imputation using those variables can give unbiased results.
  • MNAR (missing not at random): missingness depends on the unobserved value itself (high earners hide income). No imputation fully fixes it; model the mechanism, collect more data, or treat missingness as informative.

Step 3: do it without leakage

Fit the imputer on the training fold only and apply it to validation and test data; put it inside a Pipeline so cross-validation refits it per fold.

from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
num = Pipeline([("imp", SimpleImputer(strategy="median", add_indicator=True))])
cat = Pipeline([("imp", SimpleImputer(strategy="constant", fill_value="Unknown"))])
pre = ColumnTransformer([("num", num, num_cols), ("cat", cat, cat_cols)])
model = Pipeline([("pre", pre), ("clf", clf)])

Practical advice

  • Check whether missing values are encoded weirdly (-1, 999, "N/A", empty string) and standardise first.
  • Compare model performance with several strategies; sensitivity analysis shows whether conclusions depend on the choice.
  • For production, ensure the same imputation logic and defaults run at inference time, and monitor the missing rate for drift.
  • Document assumptions; for reporting, state how many records were affected.

Pitfalls

Imputing before splitting, using global means on time series, ignoring MNAR, and replacing missing values with zero when zero has meaning.
