Explain DBSCAN density-based clustering and how it discovers arbitrary-shaped clusters with noise.

ML / AI engineer · Gear 2 (Mid-level) · Unsupervised · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

DBSCAN groups points that are densely connected. A core point has at least minPts neighbours within radius eps. Clusters grow by linking core points whose neighbourhoods overlap, border points join a nearby core point, and points reachable from no core point are labelled noise. It needs no cluster count, finds arbitrary shapes and flags outliers, but struggles with varying density.

Explained in depth

Core idea

Clusters are dense regions separated by sparse regions. Two parameters:

  • eps (ε): neighbourhood radius.
  • minPts (min_samples): minimum points (including the point itself) within ε to count as dense.

Point types

  • Core point: at least minPts points within distance ε.
  • Border point: fewer than minPts neighbours but lies within ε of a core point.
  • Noise (outlier): neither core nor border.

Density relations: point q is directly density-reachable from core point p if q is within ε of p; density-reachable via a chain of core points; two points are density-connected if both are reachable from a common core. A cluster is a maximal set of density-connected points.

Algorithm

for each unvisited point p:
    neighbours = points within eps of p
    if |neighbours| < minPts: mark p as noise (may later become a border point)
    else: start a new cluster; expand: add neighbours; for each core neighbour, add its neighbours too (breadth-first), until no more reachable points

Complexity O(n log n) with a spatial index (KD-tree, ball tree) in low dimensions, O(n²) otherwise.

from sklearn.cluster import DBSCAN
from sklearn.neighbors import NearestNeighbors
from sklearn.preprocessing import StandardScaler
Xs = StandardScaler().fit_transform(X)
k = 2 * Xs.shape[1]                                    # rule of thumb minPts >= 2*dim
dist = np.sort(NearestNeighbors(n_neighbors=k).fit(Xs).kneighbors(Xs)[0][:, -1])   # k-distance plot: pick the knee as eps
labels = DBSCAN(eps=0.5, min_samples=k).fit_predict(Xs)       # label -1 means noise

Choosing parameters

  • minPts: at least dimensionality + 1; commonly 2 × dims; larger for noisy data to avoid tiny clusters (4 for 2D, higher for large datasets).
  • eps: use the k-distance graph (distance to the k-th nearest neighbour sorted ascending) and pick the knee; too small yields mostly noise, too large merges clusters.

Strengths

  • No need to specify the number of clusters.
  • Finds arbitrarily shaped clusters (crescents, rings) that K-Means cannot.
  • Built-in noise detection, so it doubles as an outlier detector.
  • Insensitive to the order of points (except border assignment) and robust to outliers.
  • Works with any distance metric (haversine for geospatial points).

Weaknesses

  • Varying densities: a single ε cannot fit both dense and sparse clusters; dense clusters split or sparse ones become noise. OPTICS and HDBSCAN (hierarchical, extracts stable clusters across ε values, with fewer parameters) address this.
  • High dimensionality: distances concentrate, so ε loses meaning; reduce dimensions first (PCA, UMAP).
  • Sensitive to ε, feature scaling, and the distance metric.
  • Border points assigned ambiguously; no cluster centres or probabilistic assignments; memory and time for large n without indexes.

Use cases

Geospatial hotspot detection, anomaly detection in logs and transactions, image segmentation, customer behaviour clusters with irregular shapes.

Pitfalls

Unscaled features, using one eps for heterogeneous density, treating noise label -1 as a cluster, and running on very high-dimensional embeddings without reduction.
