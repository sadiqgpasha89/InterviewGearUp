Compare CSS Flexbox and CSS Grid: When is each layout model appropriate?

Frontend engineer · Gear 2 (Mid-level) · CSS · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

Flexbox is a one-dimensional layout model that distributes space along a single axis, ideal for rows or columns of components. Grid is two-dimensional and lays out rows and columns together, ideal for page structure and aligned layouts. They are complementary and are often nested.

Explained in depth

Mental model

  • Flexbox: content-first, one axis at a time. Items size themselves and the container distributes leftover space. Wrapping creates new lines, but each line is laid out independently, so items in different rows do not align in columns.
  • Grid: layout-first. You define tracks (rows and columns) and place items into cells or areas, so items align on both axes.

Flexbox in practice

.toolbar { display: flex; gap: 12px; align-items: center; }
.toolbar .spacer { margin-left: auto; }          /* push the rest to the end */
.card { flex: 1 1 240px; }                       /* grow, shrink, basis */

Best for navbars, button groups, centring, form rows, card internals, and any list that should flow in one direction.

Grid in practice

.page {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr);
  grid-template-areas: "side main";
  gap: 24px;
}
.gallery { display: grid; grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)); gap: 16px; }

Best for page skeletons, dashboards, galleries, card grids that must align in rows and columns, overlapping items and complex responsive layouts without media queries.

Common pitfalls

  • Flex items have min-width: auto, so long text or images prevent shrinking and cause overflow. Add min-width: 0 (and overflow: hidden/ellipsis) on the item. In grid use minmax(0, 1fr) instead of 1fr.
  • auto-fit collapses empty tracks (items stretch), auto-fill keeps empty tracks (items keep their size).
  • Percent heights need a defined parent height; use align-items/stretch rather than height hacks.
  • Do not use order or visual reordering to change meaning, because keyboard and screen reader order follows the DOM.

Rule of thumb

If you care about rows and columns lining up, use Grid. If you are arranging a single line of things and letting content decide sizes, use Flexbox. Nest them: a grid page with flex toolbars and cards.
