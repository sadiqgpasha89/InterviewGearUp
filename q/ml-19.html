How do you handle missing data: Mean/Median imputation versus KNN versus iterative MICE?

ML / AI engineer · Gear 1 (Junior) · Preprocessing · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

Mean or median imputation is fast but shrinks variance and ignores relationships. KNN imputation fills a value from similar rows, capturing local structure but costing more. Iterative methods such as MICE model each feature with missing values from the others in repeated rounds, giving the best accuracy for complex data. First understand why values are missing (MCAR, MAR, MNAR).

Explained in depth

Types of missingness

  • MCAR: missing completely at random; deleting rows is unbiased but wasteful.
  • MAR: missingness depends on other observed columns; imputation using those columns works.
  • MNAR: missingness depends on the missing value itself (high earners hiding income); hardest, needs domain knowledge and indicators.

Good practice

  • Fit the imputer on the training data only (inside a pipeline), then apply to validation and test, to avoid leakage.
  • Add a missing indicator column, because the fact that a value is missing can itself be predictive.
  • Gradient boosting libraries (XGBoost, LightGBM, CatBoost) and some tree implementations handle missing values natively.
  • Check how much is missing: above roughly 40 to 50 percent, consider dropping the feature. Compare imputation methods by downstream model performance.
