Explain the CSS Box Model: `box-sizing: content-box` versus `border-box`.

Frontend engineer · Gear 1 (Junior) · CSS · Difficulty: easy · AI-drafted, not yet reviewed by a person

In 30 seconds

Every element is a box made of content, padding, border and margin. With the default content-box sizing, width and height set only the content area, so padding and border make the element bigger. With border-box, width and height include padding and border, which makes sizing predictable; most projects set it globally.

Explained in depth

The layers (from inside out)

  1. Content: text or children, sized by width and height.
  2. Padding: space inside the border, takes the element's background.
  3. Border: the visible edge.
  4. Margin: transparent space outside, separating siblings.

The two sizing models

.card { width: 300px; padding: 20px; border: 2px solid; }
/* content-box: total width = 300 + 2*20 + 2*2 = 344px */
/* border-box:  total width = 300px, content shrinks to 256px */

box-sizing: border-box means width and height describe the border box, so adding padding does not break layouts such as two 50% wide columns.

Common global reset

*, *::before, *::after { box-sizing: border-box; }

Details worth knowing

  • Margins are outside the box and are not part of its size. Vertical margins of adjacent block elements can collapse into the larger one.
  • Percentage padding and margin resolve against the containing block's width, even for top and bottom.
  • Inline elements ignore width and height, and their vertical padding does not push other lines apart.
  • Use browser DevTools' box model diagram to see each layer.
