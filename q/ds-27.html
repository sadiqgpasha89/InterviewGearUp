Compare PCA, t-SNE and UMAP for dimensionality reduction. When do you use each and what are the caveats?

Data scientist · Gear 2 (Mid-level) · Unsupervised learning · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

PCA is a linear, deterministic projection onto directions of maximum variance, good for compression, denoising and preprocessing. t-SNE and UMAP are non-linear embeddings for visualisation that preserve local neighbourhoods, with UMAP faster and better at global structure. Cluster sizes and distances in t-SNE and UMAP plots are not reliable, so never over-interpret them.

Explained in depth

Why reduce dimensions

High-dimensional data cause the curse of dimensionality (distances become less informative, models need more data), noise, multicollinearity, slow training, and are impossible to visualise. Reduction compresses information, denoises, speeds up learning and enables 2D or 3D plots.

PCA (principal component analysis)

  • Finds orthogonal directions (principal components) that capture maximum variance; equivalent to the SVD of the centred data. Projection onto the top k components minimises reconstruction error among linear methods.
  • Standardise features first when units differ; PCA is scale-sensitive.
  • Choose k by the explained variance ratio (cumulative 90 to 95 percent), scree plot elbow, cross-validated performance of a downstream model, or reconstruction error.
  • Strengths: fast, deterministic, invertible approximately, interpretable loadings, a useful preprocessing step for regression, clustering and removing collinearity, works for new points via a linear transform.
  • Limits: linear only; variance is not the same as relevance (a low-variance direction may carry the label signal); components can be hard to interpret; sensitive to outliers (use robust PCA).
from sklearn.decomposition import PCA
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
pca = make_pipeline(StandardScaler(), PCA(n_components=0.95, svd_solver="full")).fit(X_tr)
print(pca[-1].n_components_, pca[-1].explained_variance_ratio_[:5])

Variants: kernel PCA, sparse PCA, incremental PCA (large data), truncated SVD for sparse matrices (LSA), autoencoders (non-linear).

t-SNE

Converts pairwise similarities to probabilities in high dimensions and finds a low-dimensional layout minimising the KL divergence, using a heavy-tailed Student-t distribution in the low dimension to avoid crowding. Key parameter: perplexity (roughly the effective number of neighbours, 5 to 50), plus learning rate and iterations.

  • Excellent at revealing local cluster structure.
  • Caveats: no stable out-of-sample transform, stochastic (different runs differ), slow on large data (use openTSNE, Barnes-Hut or FIt-SNE), cluster sizes, distances between clusters and densities are not meaningful, apparent clusters can appear from noise at certain perplexities, so try several parameters and seeds.

UMAP

Builds a fuzzy nearest-neighbour graph and optimises a low-dimensional layout with a similar graph (based on manifold theory). Parameters: n_neighbors (local versus global balance), min_dist (how tightly points pack).

  • Typically faster than t-SNE, scales to millions of points, often preserves more global structure, supports transform of new data, and can be supervised or used for embedding as a feature.
  • Caveats: still distorts distances; results depend on parameters and seed; inter-cluster distances should not be over-read; can create misleading "islands".

Guidance

Use PCA for preprocessing and compression, t-SNE or UMAP for exploration (embeddings from neural networks, single-cell data, customer segments). Verify discovered structure with the original features or a clustering method and quantitative checks (trustworthiness, neighbour preservation).

Pitfalls

Interpreting cluster separation in a 2D embedding as proof, feeding t-SNE output to a classifier without care, and using PCA on unscaled mixed-unit data.
