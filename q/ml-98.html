What is cross-attention in Encoder-Decoder models and how does the decoder attend to encoder representations?

ML / AI engineer · Gear 3 (Senior) · Transformers · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

Cross-attention lets the decoder query the encoder output. Queries come from the decoder's current hidden states while keys and values come from the encoder's final representations, so each decoding step computes attention weights over source positions and takes a weighted sum of encoder information. This is how translation, summarisation and speech models align generated tokens with the input.

Explained in depth

Encoder-decoder Transformer

The original Transformer (Vaswani et al., 2017) has two stacks:

  • Encoder: N layers of self-attention plus feed-forward networks that turn the source sequence (for example a French sentence) into contextual representations H_enc (length S × d).
  • Decoder: N layers, each with three sublayers:
  1. Masked (causal) self-attention over the target tokens generated so far, so position t cannot see future tokens.
  2. Cross-attention (encoder-decoder attention) over the encoder output.
  3. Position-wise feed-forward network.

Each sublayer has residual connections and layer normalisation.

Cross-attention mechanics

In scaled dot-product attention Attention(Q, K, V) = softmax(QKᵀ / √d_k) V, the sources of Q, K, V differ:

  • Queries Q = X_dec W_Q computed from the decoder's current hidden states (the output of its masked self-attention sublayer): "what information do I need now?"
  • Keys K = H_enc W_K and Values V = H_enc W_V computed from the encoder output: "what information is available at each source position?".

The result for each decoder position is a weighted combination of source representations, with weights showing which source tokens are relevant for generating the current target token (soft alignment, interpretable as attention maps in translation: "chat" attends to "cat"). There is no causal mask because the entire source is available; only padding masks are applied.

import torch, torch.nn.functional as F
def cross_attention(dec, enc, Wq, Wk, Wv, heads, src_pad_mask=None):
    B, T, d = dec.shape; S = enc.shape[1]; dh = d // heads
    q = (dec @ Wq).view(B, T, heads, dh).transpose(1, 2)        # from decoder
    k = (enc @ Wk).view(B, S, heads, dh).transpose(1, 2)        # from encoder
    v = (enc @ Wv).view(B, S, heads, dh).transpose(1, 2)
    scores = q @ k.transpose(-2, -1) / dh ** 0.5                # (B, heads, T, S)
    if src_pad_mask is not None: scores = scores.masked_fill(src_pad_mask[:, None, None, :], float("-inf"))
    return (F.softmax(scores, -1) @ v).transpose(1, 2).reshape(B, T, d)

Multi-head cross-attention runs several such heads in parallel to capture different alignment relations, followed by an output projection.

Inference efficiency

During autoregressive generation, H_enc does not change, so K and V for cross-attention are computed once per layer and cached, while self-attention KV cache grows each step. Cross-attention cost per step is O(S·d) per layer.

Applications

  • Machine translation, summarisation, T5/BART/mT5, text-to-text tasks.
  • Speech recognition and translation (Whisper: audio encoder, text decoder with cross-attention).
  • Image captioning (image encoder, text decoder), visual question answering, Flamingo (gated cross-attention layers inserted into a frozen LLM to attend to visual features), BLIP-2 Q-Former.
  • Diffusion models: Stable Diffusion's U-Net uses cross-attention where image latents (queries) attend to text-encoder embeddings (keys and values), conditioning generation on the prompt; attention maps enable prompt-to-prompt editing.
  • Perceiver and DETR (object queries attend to image features), retrieval-augmented decoders (RETRO attends to retrieved chunks), multimodal fusion.
  • Decoder-only LLMs omit cross-attention and instead concatenate source and target in one sequence with self-attention (prefix), which is simpler but spends decoder capacity on the source.

Pitfalls

Applying a causal mask to cross-attention, forgetting encoder padding masks, recomputing encoder K and V every step, and confusing which side supplies queries versus keys and values.
