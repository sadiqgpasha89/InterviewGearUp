How do you find the running median of a data stream using two heaps (Max-Heap and Min-Heap)?

Software engineer (core) · Gear 2 (Mid-level) · Algorithms · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

Keep the smaller half of the numbers in a max-heap and the larger half in a min-heap, with their sizes differing by at most one. The median is the top of the larger heap, or the average of both tops when the sizes are equal. Each insert costs O(log N) and reading the median is O(1).

Explained in depth

Structure

  • low: max-heap with the smaller half.
  • high: min-heap with the larger half.
  • Invariants: every element of low is at most every element of high, and len(low) is either len(high) or len(high) + 1.
import heapq

class RunningMedian:
    def __init__(self):
        self.low = []    # max-heap via negated values
        self.high = []   # min-heap

    def add(self, x):
        heapq.heappush(self.low, -x)
        heapq.heappush(self.high, -heapq.heappop(self.low))   # balance values
        if len(self.high) > len(self.low):                    # balance sizes
            heapq.heappush(self.low, -heapq.heappop(self.high))

    def median(self):
        if len(self.low) > len(self.high):
            return -self.low[0]
        return (-self.low[0] + self.high[0]) / 2

Why it works

The two tops are the middle elements of the sorted data, so the median is always at the boundary between the heaps. Pushing through the other heap ensures an element ends up on the correct side.

Complexity

Insert: O(log N). Median: O(1). Space: O(N).

Variations

  • Sliding window: use lazy deletion with a hash map of pending removals, or two sorted structures.
  • Bounded integer values: a counting array or a Fenwick tree finds the median in O(log range).
