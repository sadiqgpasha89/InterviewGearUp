Explain Topological Sort on a DAG: Kahn's in-degree algorithm versus DFS post-order traversal.

Software engineer (core) · Gear 2 (Mid-level) · Graphs · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

A topological sort orders the vertices of a directed acyclic graph so that every edge goes from earlier to later. Kahn's algorithm repeatedly removes vertices with in-degree zero using a queue; the DFS method outputs vertices in reverse post-order. Both run in O(V+E), and both can detect a cycle, because a cycle leaves no valid order.

Explained in depth

Kahn's algorithm (BFS style)

from collections import deque

def topo_kahn(n, edges):
    graph = [[] for _ in range(n)]
    indeg = [0] * n
    for u, v in edges:
        graph[u].append(v)
        indeg[v] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else []   # fewer than n means a cycle

DFS post-order

Run DFS; when a vertex finishes (all its descendants are done), append it to a list. The reverse of that list is a topological order. A back edge (reaching a vertex that is still on the current path) means a cycle.

Comparison

  • Both are O(V+E) time and O(V) space.
  • Kahn's naturally detects cycles and gives layers (useful for scheduling in parallel); with a priority queue it produces the lexicographically smallest order.
  • DFS is short to write recursively but needs three states per vertex for cycle detection and can overflow the stack on deep graphs.

Uses

Build systems and task dependency graphs, course prerequisites, package installation order, and spreadsheet formula evaluation.
