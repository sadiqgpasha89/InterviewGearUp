What is the difference between supervised, unsupervised and reinforcement learning?

ML / AI engineer · Gear 1 (Junior) · Fundamentals · Difficulty: easy · AI-drafted, not yet reviewed by a person

In 30 seconds

Supervised learning learns from labelled examples to predict a known target, as in classification and regression. Unsupervised learning finds structure in unlabelled data, such as clusters. Reinforcement learning trains an agent by trial and error to maximise cumulative reward. Self-supervised learning, used for language models, creates labels from the data itself.

Explained in depth

Supervised learning

  • Training data has inputs and correct outputs (labels). The model learns a mapping and is evaluated on unseen examples.
  • Classification predicts a category (spam or not, disease or not); regression predicts a number (house price, delivery time).
  • Algorithms: linear and logistic regression, decision trees, random forests, gradient boosting, neural networks.
  • Needs labelled data, which can be costly.

Unsupervised learning

  • No labels: the algorithm discovers patterns.
  • Clustering (K-Means, DBSCAN) groups similar customers; dimensionality reduction (PCA, t-SNE, UMAP) compresses or visualises data; anomaly detection finds unusual points; association rules find items bought together.
  • Harder to evaluate because there is no ground truth, so you rely on internal metrics and domain judgement.

Reinforcement learning

  • An agent takes actions in an environment, receives rewards, and learns a policy to maximise long-term reward. Used in games, robotics, recommendations and tuning language models with human feedback.
  • Challenges: exploration versus exploitation, delayed rewards, sample inefficiency and safe training.

Between the categories

  • Semi-supervised: a small labelled set plus a large unlabelled set.
  • Self-supervised: the data supplies its own labels (predict the next word or a masked token), which powers modern large language models and image encoders.

Choosing

If you have labels for the target you care about, use supervised learning. If you want to explore or summarise data, use unsupervised methods. If decisions affect future states and you can simulate or experiment, consider reinforcement learning.
