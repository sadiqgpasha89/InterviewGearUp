Explain Random Forest internals: Bootstrap aggregation, feature subsampling, and out-of-bag error.

ML / AI engineer · Gear 2 (Mid-level) · Tree Models · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

A random forest trains many deep decision trees, each on a bootstrap sample and considering only a random subset of features at each split, then averages their predictions. The randomness decorrelates the trees, and each tree's out-of-bag samples give a free validation estimate without a separate hold-out set.

Explained in depth

Ingredients

  1. Bootstrap aggregation: each tree sees N rows drawn with replacement, so about 63% of the unique rows appear in it.
  2. Feature subsampling: at each split only a random subset of features is considered (often sqrt(p) for classification and p/3 for regression). This stops strong features from dominating every tree, so the trees are less correlated and averaging helps more.
  3. Deep, unpruned trees: low bias, high variance, which averaging then reduces.
  4. Prediction: majority vote or the mean of the trees' outputs.

Out-of-bag error

About 37% of rows are left out of each tree's bootstrap sample. Predict each row using only the trees that did not train on it, then compare with the truth. The result approximates cross-validation error with no extra training, and also works for tuning.

Feature importance

Impurity-based importance is fast but biased toward high-cardinality features. Permutation importance (shuffle a feature, measure the score drop) is more reliable, ideally on held-out or OOB data.

Key hyperparameters

n_estimators (more trees never overfit, only cost more), max_features, min_samples_leaf, max_depth.

Limitations

It cannot extrapolate beyond the training range, models can be large and slow to predict, probabilities are not well calibrated, and gradient boosting often beats it on accuracy for tabular data.

Likely follow-ups

  • Why does reducing the correlation between trees improve the ensemble?
  • Why is impurity-based feature importance biased?
  • Why can a random forest not extrapolate a trend?
