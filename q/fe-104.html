What is the virtual DOM, and why do list items need a key prop in React?

Frontend engineer · Gear 1 (Junior) · React · Difficulty: easy · AI-drafted, not yet reviewed by a person

In 30 seconds

The virtual DOM is a lightweight in-memory tree of the UI. When state changes React builds a new tree, diffs it against the previous one and applies only the minimal real DOM changes. Keys give list items a stable identity so React can match, reorder and preserve them correctly instead of recreating or mixing them up.

Explained in depth

Virtual DOM and reconciliation

Real DOM operations are comparatively costly (layout, paint). React keeps a tree of plain JavaScript objects describing the UI. After each state change it:

  1. Renders a new virtual tree.
  2. Diffs it with the previous tree (reconciliation) using fast heuristics: elements of different types are replaced, same-type elements are updated, and lists are matched by key.
  3. Commits only the differences to the real DOM.

This lets you write UI as a function of state while React batches and minimises DOM work. It is not magic: for simple pages, direct DOM updates can be faster, and the benefit is the programming model and good-enough performance.

Why keys matter

{todos.map(todo => <TodoItem key={todo.id} todo={todo} />)}

Keys tell React which item is which between renders. With stable keys React can move, insert or remove only the affected items and keep each item's state (input text, focus, animations) attached to the right data.

Choosing keys

  • Use a stable, unique ID from the data (database ID).
  • Avoid array indexes when the list can be reordered, filtered or inserted into: after inserting at the top, every index shifts, so React reuses the wrong component instances, leading to wrong input values and wasted re-renders. Indexes are acceptable only for static lists that never change.
  • Do not generate keys during render with Math.random(), because every render makes new keys and remounts every item.
  • Keys need to be unique among siblings only, and are not passed as props.
