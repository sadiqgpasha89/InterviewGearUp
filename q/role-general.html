Gear 1: Junior (0 to 2 years)

  • What is Big-O notation? Explain with examples.
  • Given an array of numbers and a target, return the indices of two numbers that add up to the target.
  • How does a dynamic array manage geometric resizing, and what is the amortized cost of an append?
  • Compare singly linked lists and doubly linked lists: Pointer overheads and operation trade-offs.
  • Explain Floyd's cycle-finding algorithm (Fast and Slow pointers) to detect loops in a linked list.
  • How do you reverse a singly linked list in-place both iteratively and recursively?
  • How do you implement a queue using two stacks, and what is the amortized cost per dequeue?
  • Explain hash table internals: Hash functions, buckets, load factor, and rehashing triggers.
  • Explain Breadth-First Search (BFS): Queue implementation and finding shortest paths in unweighted graphs.
  • Explain Depth-First Search (DFS): Stack/recursive traversal and cycle detection in directed graphs.
  • How does the two pointers technique solve the Two-Sum problem in a sorted array in $O(N)$ time?
  • Explain binary search: Classic exact match implementation and avoiding integer overflow in midpoint calculation.
  • Compare recursion and iteration: Call stack frames, memory overhead, and tail call optimization (TCO).
  • Explain bitwise operators (AND, OR, XOR, NOT, Shifts) and how XOR cancels identical numbers.
  • Define Big-O, Big-Omega, and Big-Theta asymptotic notations with mathematical bounds.
  • Explain the Single Responsibility Principle (SRP) and provide a concrete refactoring example.
  • Explain the Singleton pattern and how to implement thread-safe double-checked locking.
  • Why is Composition favored over Inheritance: Fragile base class problems and tight coupling.
  • Explain Defensive Programming: Preconditions, postconditions, and fail-fast invariants.

Gear 2: Mid-level (2 to 5 years)

  • What is the difference between a process and a thread?
  • Implement an LRU cache with O(1) get and put.
  • What is a monotonic stack and how does it find the next greater element in $O(N)$ time?
  • Compare collision resolution strategies: Separate chaining versus open addressing (linear/quadratic probing).
  • Explain Binary Search Tree (BST) operations: Insertion, deletion, and finding in-order predecessor/successor.
  • Explain binary heap array representation: Parent-child index arithmetic and $O(N)$ bottom-up heapify.
  • How do you find the Kth largest element in an unsorted array using Quickselect in $O(N)$ average time?
  • How do you find the running median of a data stream using two heaps (Max-Heap and Min-Heap)?
  • Explain the Trie (Prefix Tree) data structure: Insert, search, and prefix matching complexities.
  • Explain Disjoint Set Union (Union-Find) with path compression and union by rank optimizations.
  • Compare graph representations: Adjacency list versus adjacency matrix space and traversal trade-offs.
  • Explain Topological Sort on a DAG: Kahn's in-degree algorithm versus DFS post-order traversal.
  • Walk through Dijkstra's shortest path algorithm using a priority queue and explain why it fails with negative weights.
  • Explain Kruskal's algorithm for finding the Minimum Spanning Tree using a greedy approach and Union-Find.
  • Explain Prim's algorithm for Minimum Spanning Trees using priority queues.
  • Explain the Dutch National Flag algorithm (three-way partitioning) for sorting 0s, 1s, and 2s in-place.
  • Explain the sliding window pattern: Fixed-size window versus dynamic-size window with two pointers.
  • How do you find the longest substring without repeating characters using a sliding window and hash map?
  • How do you implement binary search to find the lower bound (first occurrence) and upper bound in sorted arrays?
  • Explain the backtracking paradigm: Generating all permutations and combinations with pruning.
  • Compare top-down memoization and bottom-up tabulation in dynamic programming.
  • Solve the Coin Change problem: Minimum coins required versus total distinct combination counts.
  • Explain the interval scheduling maximization problem and why sorting by end time is optimal.
  • Explain Brian Kernighan's algorithm for counting set bits in an integer in $O(\text{set bits})$ time.
  • How do you find the single non-duplicate number in an array where every other element appears twice?
  • Explain amortized analysis: Aggregate method, accounting method, and potential method.
  • How does the Master Theorem solve divide-and-conquer recurrence relations like $T(N) = aT(N/b) + f(N)$?
  • Compare QuickSort and MergeSort: Stability, in-place memory usage, and worst-case time complexities.
  • Explain non-comparison sorting: Counting Sort, Radix Sort, and Bucket Sort with complexity constraints.
  • Explain the Open/Closed Principle (OCP) and how the Strategy pattern adheres to it.
  • Explain the Liskov Substitution Principle (LSP) and why a Square inheriting from Rectangle violates it.
  • Explain the Interface Segregation Principle (ISP) and why fat interfaces harm maintainability.
  • Explain the Dependency Inversion Principle (DIP) and how Dependency Injection decouples high-level modules.
  • Compare Factory Method and Abstract Factory design patterns.
  • How does the Builder pattern construct complex immutable objects with optional parameters?
  • Compare the Adapter pattern and the Facade pattern: Intent and interface transformation differences.
  • Explain the Decorator pattern and how it dynamically attaches responsibilities without subclassing.
  • Explain the Proxy pattern: Virtual proxies, protection proxies, and logging proxies.
  • How does the Observer pattern decouple subjects from observers in event-driven programming?
  • How does the Strategy pattern allow swapping algorithms at runtime without conditional statements?
  • Explain the Command pattern: Encapsulating actions as objects for queueing, logging, and undo operations.
  • Explain the State pattern and how it models state machine transitions without nested switch cases.
  • Explain the Law of Demeter (Principle of Least Knowledge) and why chaining method calls violates it.
  • Explain Concurrency versus Parallelism: Thread scheduling versus physical multi-core execution.
  • What is a race condition and critical section, and how do mutexes protect shared memory?
  • Compare Mutexes, Binary Semaphores, and Counting Semaphores in thread synchronization.
  • What is the difference between Spatial Locality and Temporal Locality in array processing?
  • Explain Big-Endian and Little-Endian byte orderings and when byte-order conversion matters in network sockets.
  • How does the IEEE 754 floating-point standard represent numbers, and why does `0.1 + 0.2 != 0.3` occur?
  • Compare Garbage Collection mechanisms: Mark-and-Sweep tracing versus Reference Counting with cycle detection.
  • What is the Object Pool design pattern, and when does object reuse outperform garbage collection allocation?
  • Compare error handling strategies: Exceptions versus Result/Option monads in modern languages.
  • Explain the Boyer-Moore Majority Vote algorithm to find the majority element in $O(N)$ time and $O(1)$ space.

Gear 3: Senior (5 to 8 years)

  • Design a URL shortener.
  • Tell me about a time you disagreed with a teammate on a technical decision.
  • Explain Robin Hood hashing and how stealing from the rich reduces probe sequence variance.
  • Compare AVL trees and Red-Black trees: Rotations, height balance invariants, and read vs write trade-offs.
  • How does the Bellman-Ford algorithm compute shortest paths and detect negative weight cycles?
  • Explain the Floyd-Warshall dynamic programming algorithm for all-pairs shortest paths.
  • How does binary search on the answer space solve optimization problems like Koko Eating Bananas?
  • How do you solve the N-Queens problem using backtracking with column and diagonal constraint bitsets?
  • Solve the 0/1 Knapsack problem with 2D dynamic programming and optimize it to 1D array space.
  • How do you find the Longest Common Subsequence (LCS) of two strings using dynamic programming?
  • Explain how to find the Longest Increasing Subsequence (LIS) in $O(N \log N)$ time using patience sorting.
  • How does Huffman Coding build an optimal prefix-free binary tree for lossless data compression?
  • Explain the Knuth-Morris-Pratt (KMP) string matching algorithm and how the Longest Prefix Suffix (LPS) array works.
  • How does the Rabin-Karp string search algorithm use rolling polynomial hashes to find substrings?
  • How do you implement an LRU (Least Recently Used) cache in $O(1)$ time using a Hash Map and Doubly Linked List?
  • What are the four Coffman conditions required for deadlocks, and how can breaking one prevent deadlocks?
  • Solve the Producer-Consumer problem using a bounded buffer, condition variables, and mutexes.
  • Explain Reader-Writer locks: Reader-preference versus writer-preference starvation issues.
  • What are atomic operations and Compare-And-Swap (CAS) instructions in lock-free programming?
  • Explain CPU cache hierarchy (L1, L2, L3), cache lines (64 bytes), and false sharing in multi-threaded code.
  • How does a Segment Tree support range sum queries and point updates in $O(\log N)$ time?
  • Explain the Fenwick Tree (Binary Indexed Tree) for computing dynamic prefix sums in $O(\log N)$ time.
  • How does Tarjan's algorithm find bridges and articulation points in an undirected graph in $O(V+E)$ time?
  • How does Kosaraju's two-pass DFS algorithm identify Strongly Connected Components (SCC) in directed graphs?
  • How does a Monotonic Queue find sliding window maximums in $O(N)$ amortized time?

Gear 4: Lead / Staff (8+ years)

  • Design a rate limiter for an API platform.
  • Tell me about a technical decision you made that you later regretted.
  • How do you implement an LFU (Least Frequently Used) cache in $O(1)$ time using frequency doubly linked lists?
  • How does a lock-free queue work, and what is the ABA problem?
  • Design a web crawler that fetches billions of pages politely and keeps its index fresh.
  • Design a real-time collaborative document editor. How do Operational Transformation and CRDTs differ?
  • Design a feature flag and experimentation platform used by hundreds of services.
  • Design a distributed key-value store with high availability and tunable consistency.
  • How would you design a versioning and deprecation strategy for a public API with thousands of consumers?
  • Tell me about a time you drove a cross-team technical initiative without formal authority.
  • Design a metrics monitoring and alerting system that ingests millions of data points per second.
  • Design a file storage and synchronization service like Dropbox.
  • Design a real-time typeahead (search suggestion) service that answers in under 100 ms.
  • Two senior engineers on your team strongly disagree on a technical direction. How do you resolve it?
  • Design a chat system supporting millions of concurrent connections with delivery guarantees and message history.
