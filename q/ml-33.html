How do Residual Connections (ResNet) solve the degradation problem in very deep networks?

ML / AI engineer · Gear 2 (Mid-level) · Deep Learning · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

Very deep plain networks get worse training error than shallower ones, not from overfitting but because optimisation becomes hard (the degradation problem). A residual block adds a skip connection so the layers learn a residual F(x) with output F(x) + x. Identity becomes the easy default, and gradients flow directly through the shortcut, which makes hundreds of layers trainable.

Explained in depth

The degradation problem

Adding layers to a network should not hurt, since extra layers could simply copy the previous output (identity mapping). Yet experiments (He et al., 2015) showed a 56-layer plain network had higher training error than a 20-layer one. So the issue is optimisation, not capacity or overfitting: solvers struggle to learn identity mappings through stacked nonlinear layers.

Residual learning

Instead of learning the desired mapping H(x) directly, let the block learn the residual F(x) = H(x) - x: y = F(x) + x

class Block(nn.Module):
    def forward(self, x):
        out = self.conv2(F.relu(self.bn1(self.conv1(x))))
        out = self.bn2(out)
        return F.relu(out + x)        # skip connection

If the best choice is identity, the block only needs F(x) = 0, which is easy to learn by pushing weights toward zero.

Why it trains better

  • Gradients take a shortcut path: dy/dx = dF/dx + 1, so the gradient reaching earlier layers always contains a direct term and cannot vanish through the stack.
  • The loss surface becomes smoother.
  • Blocks behave like an ensemble of shallower paths.

Practical details

  • When the shape changes (stride or more channels), the shortcut uses a 1x1 convolution projection.
  • Bottleneck blocks (1x1, 3x3, 1x1) reduce cost in deeper ResNets (50, 101, 152 layers).
  • The same idea appears in transformers, where each attention and feed-forward sublayer adds its output to its input, and in DenseNet and U-Net skip links.
