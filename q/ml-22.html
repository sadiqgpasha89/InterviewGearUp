Compare Bagging and Boosting ensemble paradigms in machine learning.

ML / AI engineer · Gear 2 (Mid-level) · Tree Models · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

Bagging trains many independent models in parallel on bootstrap samples and averages them, which mainly reduces variance (random forests). Boosting trains models one after another, each correcting the previous errors, which mainly reduces bias (gradient boosting, AdaBoost) and is more prone to overfitting noisy data.

Explained in depth

BaggingBoosting
TrainingParallel, independentSequential, each model depends on the last
Data per modelBootstrap sampleReweighted data or residuals
Base learnerStrong, high variance (deep trees)Weak, high bias (shallow trees)
Main effectLowers varianceLowers bias (and some variance)
Overfitting riskLowHigher, especially with noisy labels
ExampleRandom forestAdaBoost, gradient boosting, XGBoost

Bagging

Bootstrap sampling gives each model a slightly different dataset. Averaging many unstable models cancels their independent errors, so variance falls while bias stays about the same. Random forests also randomise the features at each split to decorrelate the trees.

Boosting

AdaBoost increases the weights of misclassified samples. Gradient boosting fits each new tree to the negative gradient of the loss (the residuals for squared error) and adds it with a small learning rate. Many small corrections reduce bias step by step.

Choosing

Random forests are a robust default that needs little tuning and trains in parallel. Gradient boosting is often the most accurate on tabular data but needs tuning (learning rate, number of trees, depth, regularisation) and early stopping. Stacking, which trains a model on other models' predictions, is a third ensemble style.
