How do CSS subgrid and `minmax()` solve nested grid alignment problems?

Frontend engineer · Gear 3 (Senior) · CSS · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

With subgrid a nested grid adopts its parent's row or column tracks instead of defining new ones, so deeply nested items align to the outer lines. minmax(min, max) gives a track a flexible size range, and together they solve cross-card alignment and overflow problems that nested independent grids cannot.

Explained in depth

The nesting problem

A grid item that itself becomes a grid creates independent tracks. Each card in a row of cards has its own internal rows, so a title that wraps to two lines in one card pushes only that card's content down. Titles, descriptions and buttons no longer line up across cards, and you must guess fixed heights.

Subgrid

.cards { display: grid; grid-template-columns: repeat(3, 1fr); grid-template-rows: auto; gap: 24px; }

.card {
  display: grid;
  grid-row: span 3;                    /* the card occupies 3 parent rows */
  grid-template-rows: subgrid;         /* adopt those parent rows */
  row-gap: 0;
}
/* children: <h3>, <p>, <a class="btn"> now sit in the parent's 3 shared rows */

Row sizes are computed across all cards together, so the tallest title defines row 1 for every card, the longest paragraph defines row 2, and buttons align along the bottom. You can also use grid-template-columns: subgrid for forms (labels and fields aligned across rows) and table-like layouts.

Gaps are inherited unless overridden, and line names in the parent are available to the subgrid.

minmax()

minmax(min, max) defines a track size range: the track is at least min and grows up to max.

grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));    /* responsive columns, no media queries */
grid-template-columns: minmax(0, 1fr) 320px;                    /* flexible main column that can shrink */

Key detail: 1fr is really minmax(auto, 1fr), and auto minimum means the track will not shrink below its min-content (a long word, an image, a pre block), causing overflow. Writing minmax(0, 1fr) allows the track to shrink below content size, so you can truncate or wrap.

Combined use

Responsive card grid with repeat(auto-fit, minmax(260px, 1fr)) for columns, and subgrid for the inner rows of each card, giving aligned rows without JavaScript equalisers or fixed heights.

Fallbacks

Subgrid is supported in all current evergreen browsers (Firefox first, Chrome and Safari later). Use @supports (grid-template-rows: subgrid) to enhance, with a flex column fallback (margin-top: auto on buttons) for older browsers.

Pitfalls

The item must span the parent tracks it wants to share; padding on the subgrid element shifts its children relative to parent lines; implicit tracks are not created in subgrid dimension; and heavy use makes layout recomputation more complex, so test with long content and translations.
