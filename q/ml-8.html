Explain the Bias-Variance tradeoff and how it relates to model underfitting and overfitting.

ML / AI engineer · Gear 1 (Junior) · Fundamentals · Difficulty: easy · AI-drafted, not yet reviewed by a person

In 30 seconds

Bias is error from overly simple assumptions (underfitting); variance is error from sensitivity to the training data (overfitting). Expected test error splits into bias squared, variance and irreducible noise. Making a model more complex lowers bias but raises variance, so the goal is the complexity at which total validation error is lowest.

Explained in depth

The decomposition

For squared error, the expected prediction error at a point is: Error = Bias^2 + Variance + Irreducible noise

  • Bias: how far the average prediction (over many training sets) is from the truth. High bias means the model is too rigid, for example a straight line for curved data.
  • Variance: how much predictions change if you train on a different sample. High variance means the model chases noise.
  • Irreducible noise: randomness in the data that no model can remove.

Underfitting and overfitting

High bias (underfit)High variance (overfit)
Training errorHighVery low
Validation errorHigh, close to trainingMuch higher than training
Typical causeToo simple a model, too few features, too much regularisationToo complex a model, too little data, noisy features

Remedies

  • Fix high bias: a more flexible model, extra or better features, less regularisation, longer training.
  • Fix high variance: more training data, regularisation (L1, L2, dropout), simpler model, early stopping, ensembling and bagging, feature selection.

Diagnosing

Plot learning curves (error versus training size). If both training and validation errors are high and converge, add capacity (bias). If there is a large gap, add data or regularise (variance). Use cross-validation to choose complexity.

Modern note

Very large, over-parameterised networks can fit the training set perfectly and still generalise (double descent), so the simple U-shaped picture is incomplete, but the trade-off remains a useful guide for classical models.

Likely follow-ups

  • How do learning curves show whether a model suffers from high bias or high variance?
  • How does regularisation move you along the trade-off?
  • Does the classic trade-off still hold for very large neural networks?
