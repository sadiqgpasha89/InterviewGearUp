What is a firewall, and how do stateless, stateful and application-layer firewalls differ?

Security engineer · Gear 1 (Junior) · Network security · Difficulty: easy · AI-drafted, not yet reviewed by a person

In 30 seconds

A firewall filters network traffic according to rules about addresses, ports, protocols and sometimes content. Stateless firewalls judge each packet alone, stateful firewalls track connections and allow replies to permitted requests, and application-layer or next-generation firewalls inspect traffic content, applications and users. Use default deny, least-open rules and layered defences.

Explained in depth

Purpose

A firewall enforces network policy between zones (internet, internal network, DMZ, cloud VPCs): which traffic may pass, in which direction.

Types

TypeHow it decidesNotes
Stateless packet filterExamines each packet in isolation (source and destination IP, port, protocol, flags)Fast and simple; must explicitly allow return traffic; examples: cloud network ACLs
Stateful firewallTracks connection state in a table; automatically permits replies for allowed outbound connections and blocks unsolicited inbound onesStandard today; examples: Linux iptables and nftables with conntrack, cloud security groups
Application-layer (proxy, NGFW)Inspects payload and application protocol; identifies applications (not just ports), users, TLS contents, malware and intrusion signaturesMore powerful, more expensive and CPU-intensive; needs TLS inspection to see encrypted traffic
Web application firewall (WAF)Understands HTTP and blocks attacks such as SQL injection and XSSProtects web apps specifically

Good rule design

  • Default deny: block everything, then allow only what is needed (specific sources, ports and protocols).
  • Least privilege and segmentation: separate web, application and database tiers; limit lateral movement between them.
  • Control egress too, not only ingress, to limit data exfiltration and command-and-control traffic.
  • Keep rules documented, reviewed and cleaned up (remove unused ones), and log denied traffic for detection.

In the cloud

Security groups (stateful, attached to instances) and network ACLs (stateless, on subnets) provide layered filtering. Combine with private subnets, no public IPs on databases, and managed WAF and DDoS services.

Limits

Firewalls do not stop attacks over allowed channels (a phished user, a vulnerable web app on port 443), so combine them with patching, authentication, monitoring and endpoint protection.
