Explain Principal Component Analysis (PCA) dimensionality reduction using covariance matrix eigenvectors.

ML / AI engineer · Gear 2 (Mid-level) · Unsupervised · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

PCA finds orthogonal directions of maximum variance. Centre the data, compute the covariance matrix, take its eigenvectors as principal components and eigenvalues as the variance each explains, then project onto the top k components. In practice it is computed through the singular value decomposition of the centred data, which is more numerically stable.

Explained in depth

Goal

Reduce dimensionality while keeping as much variance (information) as possible, for visualisation, noise reduction, decorrelation, compression and speeding up models. PCA is a linear transformation.

Derivation sketch

Given data matrix X (n samples × d features):

  1. Centre each feature: X_c = X − mean. (Also scale to unit variance when features have different units.)
  2. Covariance matrix: C = X_cᵀ X_c / (n − 1) (d × d, symmetric positive semi-definite).
  3. Eigen-decomposition: C v = λ v. Eigenvectors v₁, ..., v_d are orthonormal principal directions; eigenvalues λ₁ ≥ λ₂ ≥ ... ≥ λ_d ≥ 0 equal the variance of the data along each direction.
  4. Why eigenvectors maximise variance: projecting onto a unit vector w gives variance wᵀ C w. Maximising it subject to ‖w‖ = 1 (Lagrange multiplier) gives C w = λ w, so the maximiser is the eigenvector of the largest eigenvalue, and the variance equals λ. The next component maximises variance among directions orthogonal to the first, and so on.
  5. Project: choose top k eigenvectors W_k (d × k) and compute Z = X_c W_k (n × k). Reconstruct approximately with X̂ = Z W_kᵀ + mean.
  6. Explained variance ratio of component j: λ_j / Σ λ. Keep k so that the cumulative ratio reaches, for example, 90 to 95 percent, or use a scree plot (elbow), or cross-validated reconstruction or downstream performance.

SVD route

X_c = U Σ Vᵀ. Columns of V are principal directions; λ_j = σ_j² / (n − 1); scores Z = U Σ. SVD avoids forming the covariance matrix explicitly (better numerically, and truncated or randomised SVD handles large matrices).

from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
pipe = make_pipeline(StandardScaler(), PCA(n_components=0.95, svd_solver="full"))   # keep 95% variance
Z = pipe.fit_transform(X)
pca = pipe.named_steps["pca"]
print(pca.n_components_, pca.explained_variance_ratio_.cumsum())
# manual
Xc = (X - X.mean(0)) / X.std(0)
vals, vecs = np.linalg.eigh(np.cov(Xc, rowvar=False))
order = np.argsort(vals)[::-1]; W = vecs[:, order[:2]]; Z2 = Xc @ W

Practical notes

  • Standardise when features have different scales; otherwise large-scale features dominate the components. (Use covariance PCA only if units are comparable; otherwise correlation PCA.)
  • Fit PCA on training data only and reuse the fitted transform on validation and test data (avoid leakage).
  • Components are linear combinations and are less interpretable; loadings show feature contributions. Signs are arbitrary.
  • Useful for multicollinearity, denoising (drop low-variance components), visualisation (2D or 3D), eigenfaces, preprocessing for clustering and regression (PCR).
  • Variants: Incremental PCA for streaming or large data, Randomized PCA, Sparse PCA for interpretability, Kernel PCA for nonlinear structure, probabilistic PCA.

Limitations

Only captures linear structure and variance (high variance is not always high signal for a target); sensitive to outliers and scaling; assumes meaningful directions are orthogonal; for visualising nonlinear manifolds use t-SNE or UMAP (which do not preserve global distances) or autoencoders. Supervised alternatives: LDA, PLS.

Pitfalls

Forgetting to scale, fitting on the whole dataset before splitting, interpreting components as original features, choosing k by variance alone when the task needs low-variance directions, and applying PCA to categorical one-hot data without thought.
