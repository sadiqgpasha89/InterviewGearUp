How do you interpret logistic regression coefficients, and how is the model fitted and diagnosed?

Data scientist · Gear 3 (Senior) · Regression and classification · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

Logistic regression models the log-odds of the outcome as a linear function of features and is fitted by maximum likelihood. Coefficients are log odds ratios, so exp(beta) is the multiplicative change in odds per unit increase. Check calibration, separation, multicollinearity, linearity in the logit and influential points, and use regularisation when features are many.

Explained in depth

Model

For a binary outcome y, logistic regression assumes log-odds = b0 + b1 x1 + ... + bp xp, so P(y = 1 | x) = 1 / (1 + exp(-(b0 + b·x))). It belongs to the generalised linear models (Bernoulli distribution, logit link).

Fitting

Parameters are estimated by maximum likelihood: maximise sum of y log p + (1 - y) log(1 - p), equivalently minimise log loss (cross-entropy). There is no closed form; solvers use iteratively reweighted least squares or quasi-Newton / gradient methods. The loss is convex, so there is a single optimum (unless the data are perfectly separable). Add L2 (ridge) or L1 (lasso) penalties to control overfitting and handle collinearity; scikit-learn applies L2 by default (parameter C is the inverse strength).

Interpreting coefficients

  • b_j is the change in log-odds for a one-unit increase in x_j, holding others fixed.
  • exp(b_j) is the odds ratio: b = 0.69 gives OR = 2, so the odds double. With a binary feature, it compares groups.
  • The effect on probability is not constant: it depends on the baseline (an OR of 2 moves 50 percent odds-of-1 to 67 percent, but 1 percent to about 2 percent). Report average marginal effects or predicted probabilities for representative cases.
  • Standardise continuous features to compare effect sizes; interpret "per standard deviation" changes.
  • Coefficients are conditional on the other variables; correlated features change signs and magnitudes.
import statsmodels.api as sm, numpy as np
res = sm.Logit(y, sm.add_constant(X)).fit()
print(res.summary())
print(np.exp(res.params), np.exp(res.conf_int()))     # odds ratios with intervals
print(res.get_margeff().summary())                     # average marginal effects

Diagnostics

  • Calibration (reliability curve, Hosmer-Lemeshow, calibration slope) and discrimination (AUC, PR AUC).
  • Linearity in the logit for continuous predictors: check with splines, binned plots or Box-Tidwell; add transformations or interactions as needed.
  • Multicollinearity: variance inflation factors; unstable coefficients with huge standard errors.
  • Influential points and outliers: Cook's distance, leverage, deviance residuals.
  • Complete or quasi-complete separation: a feature perfectly predicts the outcome, coefficients diverge to infinity; fix with regularisation, Firth penalised likelihood, merging categories, or removing the culprit.
  • Sample size: roughly 10 or more events per variable is a rule of thumb for stable estimation; more for prediction.
  • Independence of observations (clustered data need mixed models or cluster-robust errors).

Thresholds and use

The model outputs probabilities; the decision threshold comes from costs (cost of false negative versus false positive) and capacity, not automatically 0.5. With class weights the probabilities become distorted; recalibrate if you use them as probabilities.

Strengths and limits

Strengths: interpretable, fast, well-calibrated when specified correctly, strong baseline, works with small data, supports inference. Limits: linear decision boundary in the log-odds (add interactions or splines), sensitive to outliers and missing data handling, needs feature engineering for non-linear effects.

Pitfalls

Calling coefficients "percentage point" effects, ignoring separation warnings, interpreting p-values of correlated predictors individually, and comparing raw coefficients across differently scaled features.
