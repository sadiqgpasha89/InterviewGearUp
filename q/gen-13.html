What is a monotonic stack and how does it find the next greater element in $O(N)$ time?

Software engineer (core) · Gear 2 (Mid-level) · Data structures · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

A monotonic stack keeps its elements in sorted order. To find the next greater element, scan left to right and pop every stack element smaller than the current value, since the current value is its answer, then push the current index. Each element is pushed and popped once, so the whole scan is O(N).

Explained in depth

Idea

Keep a stack of indexes whose answers are still unknown, with their values in decreasing order from bottom to top. When a new value arrives that is larger than the top, it is the next greater element for the top (and for every smaller entry below it).

def next_greater(nums):
    res = [-1] * len(nums)
    stack = []                       # indexes, values decreasing
    for i, x in enumerate(nums):
        while stack and nums[stack[-1]] < x:
            res[stack.pop()] = x     # x is the answer for these
        stack.append(i)
    return res

# [2, 1, 2, 4, 3] -> [4, 2, 4, -1, -1]

Complexity

Every index is pushed once and popped at most once, so the total number of operations is at most 2N. Time is O(N) and space is O(N).

Variations

  • Next smaller element: flip the comparison.
  • Circular array: loop over 2N positions using i % N.
  • Daily temperatures, stock span, largest rectangle in histogram and trapping rain water all use the same pattern.

Pitfall

Store indexes, not values, when you need distances or when values repeat. Decide whether equal values should pop (strictly greater versus greater or equal).
