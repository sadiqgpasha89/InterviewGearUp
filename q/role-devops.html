DevOps / SRE / Cloud interview questions

Gear 1: Junior (0 to 2 years)

  • What is the difference between a container and a virtual machine? And an image versus a container?
  • What are CI and CD, and what does a good pipeline look like?
  • Explain the difference between CPU Load Average and CPU Utilization percentage in Linux.
  • What is Infrastructure as Code and why is it preferred over configuring cloud resources by hand?
  • How do you write a Dockerfile that builds quickly and produces a small image?
  • Compare trunk-based development with GitFlow. Which branching strategy suits continuous delivery?
  • A Linux server feels slow. What commands do you run in the first few minutes to find out why?
  • How should secrets such as API keys and passwords be handled in code and CI/CD pipelines?
  • What is the difference between Docker volumes and bind mounts, and how do you persist container data?
  • What are the core Kubernetes objects (Pod, ReplicaSet, Deployment, Service, ConfigMap, Secret) and how do they relate?
  • What are the three pillars of observability (logs, metrics and traces), and how do they differ from basic monitoring?
  • How does SSH key-based authentication work, and how do you use it securely?
  • What is the difference between horizontal and vertical scaling, and when would you use each?
  • What are the basics of cloud IAM: users, groups, roles and policies, and how do you apply least privilege?
  • What is a CDN and how does it improve performance and reliability?

Gear 2: Mid-level (2 to 5 years)

  • How does a Kubernetes rolling update work? Explain readiness versus liveness probes.
  • A Pod is stuck in CrashLoopBackOff. How do you debug it?
  • What is Terraform state, and why use a remote backend with locking?
  • What are Linux process states (Running, Sleeping, Zombie, Stopped, Disk Sleep) and how do you handle zombies?
  • Explain Linux virtual memory, Resident Set Size (RSS), swap space, and what triggers the OOM Killer.
  • What are file system inodes, and how can a disk run out of space when `df -h` shows available megabytes?
  • What are file descriptors, how do you inspect open sockets with `lsof`, and how do you adjust `ulimit`?
  • How does `systemd` supervise background services, restart failed daemons, and manage unit dependencies?
  • Explain the difference between `SIGTERM` (15), `SIGKILL` (9), and `SIGHUP` (1) signals in process management.
  • Walk through the TCP three-way handshake and four-way connection termination states.
  • What causes socket exhaustion in `TIME_WAIT` state and how do you tune `tcp_tw_reuse` and ephemeral ports?
  • Explain Maximum Transmission Unit (MTU), Path MTU Discovery (PMTUD), and packet fragmentation issues.
  • Walk through the end-to-end DNS resolution flow from stub resolver to authoritative nameservers.
  • How does subnetting and CIDR notation (e.g., `/24`, `/16`) allocate IP address ranges in a cloud VPC?
  • Compare Layer 4 (TCP/UDP) and Layer 7 (HTTP) load balancing algorithms and use cases.
  • What Linux namespaces (PID, Net, MNT, IPC, UTS, User) provide container isolation?
  • How do control groups (cgroups v1 vs v2) enforce CPU and memory resource limits on containers?
  • Explain the OverlayFS union filesystem: LowerDir, UpperDir, WorkDir, and MergedDir layers.
  • How do multi-stage Docker builds minimize container image size and eliminate build toolchains?
  • Explain the Pod lifecycle phases (Pending, Running, Succeeded, Failed, Unknown) and container restart policies.
  • Compare Kubernetes Liveness, Readiness, and Startup probes and the impact of incorrect probe configurations.
  • What is the difference between Kubernetes Deployments, StatefulSets, and DaemonSets?
  • How does a Kubernetes Service abstract pods using ClusterIP, NodePort, and LoadBalancer types?
  • How do Helm charts parameterize Kubernetes manifests, and how do you manage versioned releases?
  • How does Terraform manage remote state and state locking with Amazon S3 and DynamoDB?
  • Explain Terraform modules, input variables, outputs, and best practices for reusable infrastructure code.
  • How do you optimize CI pipeline execution speed using Docker layer caching and dependency caching?
  • Define Service Level Indicators (SLI), Service Level Objectives (SLO), and Service Level Agreements (SLA).
  • Explain the Four Golden Signals of monitoring: Latency, Traffic, Errors, and Saturation.
  • Explain Prometheus metrics architecture: Counter, Gauge, Histogram, and Summary metric types.
  • How do you scan container images for Common Vulnerabilities and Exposures (CVEs) with Trivy?
  • How do Kubernetes Persistent Volumes (PV) and PersistentVolumeClaims (PVC) bind to cloud storage?
  • What are Terraform lifecycle rules (`create_before_destroy`, `prevent_destroy`, `ignore_changes`)?
  • How do you implement pipeline gating with automated integration test suites and security scans?
  • How do you configure synthetic monitoring to continuously probe critical user journeys from the outside?
  • What is the Linux page cache, and why is high cache memory usage normal and beneficial?
  • How do you implement semantic versioning and automated changelog generation in release pipelines?
  • How do you configure Grafana dashboard alert rules and multi-channel notifications?
  • How does `iptables` NAT (Network Address Translation) forward traffic in container environments?
  • What is DNS TTL (Time-To-Live) and how does DNS caching impact zero-downtime traffic switching?

Gear 3: Senior (5 to 8 years)

  • Explain SLIs, SLOs and error budgets. How would you define them for a service?
  • Production latency has spiked. Walk me through how you respond.
  • What are rootless containers and how do user namespaces prevent privilege escalation attacks?
  • Compare container runtimes: Docker daemon versus containerd versus CRI-O and OCI specifications.
  • Explain the Kubernetes control plane architecture: API Server, etcd, Scheduler, and Controller Manager.
  • How does etcd maintain distributed consensus in Kubernetes, and what happens if etcd loses quorum?
  • Explain how an Ingress Controller routes external HTTP traffic to internal services using Gateway API.
  • How does the Horizontal Pod Autoscaler (HPA) scale pods based on metrics, and how does KEDA extend it?
  • What are PodDisruptionBudgets (PDB) and why are they critical during node upgrades and drain events?
  • Explain Node Affinity, Pod Anti-Affinity, Taints, and Tolerations for advanced pod scheduling.
  • How do Kubernetes NetworkPolicies isolate traffic between namespaces and pods using CNI plugins?
  • What are Custom Resource Definitions (CRDs) and the Kubernetes Operator pattern?
  • What is Terraform drift detection, and how do you reconcile infrastructure modified outside Terraform?
  • How does Terragrunt keep Terraform configurations DRY across multiple environments and accounts?
  • What are the core principles of GitOps, and how does pull-based reconciliation differ from push-based CI/CD?
  • How does ArgoCD detect and automatically sync application state between Git repositories and Kubernetes?
  • How do you securely manage secrets in a GitOps workflow using Sealed Secrets or External Secrets Operator?
  • How do you implement automated Canary deployments with progressive traffic shifting and metric rollbacks?
  • Explain Blue-Green deployment architecture on Kubernetes with zero downtime and fast cutover.
  • How does HashiCorp Vault manage dynamic, short-lived database and cloud credentials in CI/CD pipelines?
  • How do you calculate and manage error budgets to balance feature release velocity with system stability?
  • How do PromQL `rate()`, `irate()`, and `histogram_quantile()` functions calculate 99th percentile latency?
  • How does Prometheus Alertmanager handle alert deduplication, grouping, inhibition, and silencing?
  • How does OpenTelemetry collect, process, and export distributed traces, metrics, and logs?
  • How do you structure and conduct a blameless postmortem following a major production outage?
  • How do you design a high-reliability on-call rotation that prevents alert fatigue and burnout?
  • How does `strace` attach to running processes to diagnose system call bottlenecks and file locks?
  • How do `tcpdump` and `Wireshark` capture and analyze network packets to diagnose packet drops?
  • Explain TLS 1.3 handshake optimization and how 0-RTT resumption reduces connection latency.
  • What is Kubelet, and how does the Container Runtime Interface (CRI) execute pod containers?
  • How does CoreDNS resolve internal cluster domain names (`service.namespace.svc.cluster.local`)?
  • What are Kubernetes Admission Webhooks (Mutating and Validating) and how does OPA Gatekeeper use them?
  • Explain Kubernetes node drain (`kubectl drain`) and how eviction policies terminate workloads safely.
  • How does AWS IAM Role Assumption (`sts:AssumeRole`) enable cross-account access securely?
  • How does GCP Workload Identity allow Kubernetes pods to access cloud resources without static JSON keys?
  • What are the operational and cost trade-offs of using Spot/Preemptible instances in production clusters?
  • How do you import existing untracked cloud infrastructure into Terraform state safely?
  • How do you secure CI/CD runners using ephemeral VMs, OIDC authentication, and restricted network egress?
  • How do centralized logging architectures (Fluent Bit, Kafka, ClickHouse/OpenSearch) handle log spikes?
  • What is an Incident Commander (IC) and what are the primary responsibilities during a Sev-1 outage?
  • Explain the difference between soft interrupts (softirqs) and hard interrupts in network performance.
  • What is an IP Virtual Server (IPVS) and why is it faster than iptables for large Kubernetes clusters?
  • How do seccomp profiles and AppArmor security modules restrict containerized system calls?
  • What is the Vertical Pod Autoscaler (VPA) and how does it dynamically resize pod CPU and memory requests?
  • How do VPC Peering, Transit Gateways, and PrivateLink connect isolated private cloud networks?
  • What strategies minimize cloud egress costs across availability zones and regions?
  • How do you test Terraform modules using automated testing frameworks like Terratest?
  • How do you handle rollbacks in GitOps: `git revert` versus ArgoCD manual rollback overrides?
  • What is high cardinality in metric TSDBs and how does it cause Prometheus out-of-memory crashes?
  • How do you conduct architectural capacity planning and rightsizing for high-traffic peak events?

Gear 4: Lead / Staff (8+ years)

  • Design a multi-region setup for a critical service with a defined RTO and RPO.
  • What is a Service Mesh (Istio, Linkerd) and how does a sidecar proxy provide mTLS and traffic shaping?
  • What are the core principles of Chaos Engineering, and how does Chaos Mesh inject controlled failures?
  • How does Border Gateway Protocol (BGP) and Anycast routing route user traffic to the nearest edge PoP?
  • How do you architect a multi-region disaster recovery (Active-Passive vs Active-Active) strategy?
  • How does Kubernetes handle split-brain in multi-master clusters during network partitions?
  • What is Cilium CNI and how does extended Berkeley Packet Filter (eBPF) accelerate pod networking?
  • How would you design a CI/CD platform that serves 500 engineers and thousands of repositories?
  • How do you design multi-tenancy on Kubernetes: namespaces per team, shared clusters or separate clusters?
  • How would you design a cloud landing zone and multi-account structure for a growing company?
  • How do you build a FinOps programme that cuts cloud cost without slowing engineering teams?
  • How do you upgrade Kubernetes safely across dozens of clusters with minimal disruption?
  • How would you set up an SRE practice and reliability targets for an organisation with many services?
  • How would you design an internal developer platform and measure whether it is successful?
  • How do you design an observability architecture that scales to thousands of services while controlling cost?
