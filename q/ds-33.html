What is CUPED and how else can you reduce variance in A/B tests to detect smaller effects faster?

Data scientist · Gear 3 (Senior) · Experimentation · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

CUPED uses a pre-experiment covariate, typically the same metric before the test, to subtract predictable variation from the outcome, shrinking variance without biasing the estimate. Together with stratification, ratio-metric handling by the delta method, winsorising and triggered analysis it shortens experiments or lets you detect smaller lifts.

Explained in depth

Why variance matters

The required sample size is proportional to variance / (minimum detectable effect)^2. Halving the variance halves the needed sample (or time). Online metrics (revenue, sessions) are noisy and heavy-tailed, so variance reduction is very valuable.

CUPED (Controlled-experiment Using Pre-Experiment Data)

Take a covariate X measured before the experiment (for example the user's metric in the previous 4 weeks) that correlates with outcome Y. Compute the adjusted metric: Y_cuped = Y - theta (X - mean(X)), with theta = Cov(X, Y) / Var(X) estimated on pooled data.

  • Because X is determined before randomisation, it is independent of treatment, so the adjusted difference in means remains unbiased; the mean(X) term re-centres.
  • Variance reduces by a factor of (1 - rho^2), where rho is the correlation between X and Y. A correlation of 0.7 cuts variance about 51 percent; 0.3 only 9 percent.
  • It is equivalent to a regression adjustment (ANCOVA): regress Y on treatment and X.
import numpy as np
theta = np.cov(x_pre, y)[0, 1] / np.var(x_pre, ddof=1)
y_adj = y - theta * (x_pre - x_pre.mean())
effect = y_adj[t == 1].mean() - y_adj[t == 0].mean()

Practicalities: use pre-period data of the same unit; for users with no history, set X to the mean with a missing-indicator; do not use post-treatment covariates; compute theta from pooled arms; CUPAC extends the idea by using a ML-predicted covariate built from pre-experiment features.

Other variance-reduction techniques

TechniqueHow it helps
Stratification / post-stratificationanalyse within strata (platform, country, tenure) and combine; removes between-strata variance
Regression with covariatesgeneralises CUPED to several pre-period features
Triggered (counterfactual-aware) analysisanalyse only users who could be affected (reached the changed screen); dilution from unaffected users disappears
Winsorising / capping outlierslimit influence of extreme spenders; bias-variance trade-off, decide before the test
Delta method for ratio metricscorrect variance for metrics like sum(revenue) / sum(sessions) where numerator and denominator vary together
Choosing a more sensitive metricproxy with lower variance (conversion instead of revenue); use a validated surrogate
Blocking or paired designsrandomise within matched pairs
Longer exposure or larger traffic sharedirect, but costs time and risk
Bayesian shrinkage / hierarchical modelspool information across segments
Sequential testingstop early with valid inference when effects are large

Ratio metrics

Per-session metrics have a unit of analysis different from the unit of randomisation (users). Computing a t-test over sessions treats correlated sessions as independent and understates variance. Use the delta method or bootstrap at the user level.

Pitfalls

Using pre-period covariates contaminated by the treatment (an earlier overlapping experiment), choosing covariates after seeing results, winsorising thresholds picked post hoc, and assuming high correlation exists when metrics are new-user driven.
