Explain XML External Entity (XXE) attacks and how disabling external DTD parsing prevents file exfiltration.

Security engineer · Gear 2 (Mid-level) · AppSec · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

XXE happens when an XML parser resolves external entities defined in a DOCTYPE, letting an attacker make the server read local files (file:///etc/passwd), reach internal URLs (SSRF) or consume resources. The fix is to disable DTD and external entity processing in the parser, or use a data format such as JSON that has no such feature.

Explained in depth

The attack

XML allows entities defined in a Document Type Definition (DTD). An external entity pulls content from a URI when the document is parsed:

<?xml version="1.0"?>
<!DOCTYPE data [ <!ENTITY xxe SYSTEM "file:///etc/passwd"> ]>
<data><name>&xxe;</name></data>

If the application echoes the parsed name field, the response contains the file. Even without echo, the attacker can:

  • Read files, secrets and cloud credentials.
  • Trigger SSRF by pointing the entity at internal HTTP endpoints (for example a cloud metadata service).
  • Use out-of-band channels (parameter entities loading an attacker's DTD) to send data to a server they control.
  • Cause denial of service with nested entity expansion (billion laughs).

Where it appears

SOAP and XML APIs, file uploads that are XML under the hood (DOCX, XLSX, SVG), SAML, RSS importers and configuration parsers.

Prevention

  • Disable DTDs entirely where possible, or at least disable external entities and external DTD loading.
DocumentBuilderFactory f = DocumentBuilderFactory.newInstance();
f.setFeature("http://apache.org/xml/features/disallow-doctype-decl", true);
f.setFeature("http://xml.org/sax/features/external-general-entities", false);
f.setFeature("http://xml.org/sax/features/external-parameter-entities", false);
f.setXIncludeAware(false);
f.setExpandEntityReferences(false);
  • In Python, use defusedxml; in .NET set DtdProcessing = Prohibit; in libxml2 avoid NOENT.
  • Keep parsers updated, and prefer JSON for new APIs.
  • Run the application with least privilege and restrict outbound network access, which limits SSRF and exfiltration even if parsing is misconfigured.
  • Detect with SAST, DAST and tests that send entity payloads.
