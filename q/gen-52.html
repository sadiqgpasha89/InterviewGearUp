Explain Brian Kernighan's algorithm for counting set bits in an integer in $O(\text{set bits})$ time.

Software engineer (core) · Gear 2 (Mid-level) · Bit manipulation · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

Brian Kernighan's trick clears the lowest set bit with n &= n - 1, so the loop runs once per set bit instead of once per bit position. Counting k set bits takes O(k) time, which beats shifting through all 32 or 64 bits when the number is sparse.

Explained in depth

The algorithm

int count_bits(unsigned n) {
    int c = 0;
    while (n) {
        n &= n - 1;     // clear the lowest set bit
        c++;
    }
    return c;
}

The loop body executes once per set bit, so the cost is O(k) where k is the popcount, compared to O(w) (word width) for the naive n & 1; n >>= 1 loop.

Why n & (n - 1) works

Subtracting 1 from n flips the lowest set bit to 0 and turns every zero below it into a 1. Everything above the lowest set bit is unchanged.

n      = 1011 1000
n - 1  = 1011 0111
n&n-1  = 1011 0000   (lowest set bit cleared)

ANDing keeps the unchanged high bits and zeroes the flipped region, so exactly one bit is removed per iteration.

Useful consequences

  • Power of two test: n > 0 && (n & (n - 1)) == 0 (a power of two has a single set bit).
  • Hamming distance between a and b: popcount of a ^ b.
  • Isolate the lowest set bit: n & -n.
  • Iterate over set bits (for bitmask DP over subsets): while (m) { low = m & -m; ...; m ^= low; }.

Alternatives

MethodTimeNotes
Shift and test every bitO(w)simplest, slowest for sparse values
KernighanO(k)great when few bits are set
Lookup table (256 or 65536 entries)O(w / table bits)extra memory, cache effects

Hardware POPCNTO(1)__builtin_popcount, Integer.bitCount, int.bit_count()

Practical advice

In production use the language intrinsic (Integer.bitCount, __builtin_popcountll, int.bit_count() in Python 3.10+). It compiles to a single POPCNT instruction on modern CPUs. Know Kernighan for interviews and for languages or targets without the intrinsic.

Pitfalls

In languages with arbitrary sized or signed integers, n must be non-negative or masked to a fixed width, otherwise negative numbers either loop forever (Python) or rely on two's complement behaviour (Java >> versus >>>).
