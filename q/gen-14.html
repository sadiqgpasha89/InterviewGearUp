How do you implement a queue using two stacks, and what is the amortized cost per dequeue?

Software engineer (core) · Gear 1 (Junior) · Data structures · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

Use an input stack for enqueue and an output stack for dequeue. When the output stack is empty, pour every element from the input stack into it, which reverses the order. Each element moves at most twice, so enqueue is O(1) and dequeue is O(1) amortized, although a single dequeue can cost O(n).

Explained in depth

Idea

A stack reverses order. Reversing twice restores the original order, which is what a queue needs.

class MyQueue:
    def __init__(self):
        self.inp = []
        self.out = []

    def push(self, x):
        self.inp.append(x)              # O(1)

    def pop(self):
        self._shift()
        return self.out.pop()

    def peek(self):
        self._shift()
        return self.out[-1]

    def _shift(self):
        if not self.out:                # only refill when empty
            while self.inp:
                self.out.append(self.inp.pop())

Why amortized O(1)

The transfer happens only when out is empty. Every element is pushed onto inp once, moved to out once and popped from out once, so at most three operations per element. Over n operations the total work is O(n), which gives O(1) amortized per operation.

Common mistakes

  • Moving elements back to the input stack after each operation, which makes every dequeue O(n).
  • Refilling out while it still has elements, which breaks the order.
