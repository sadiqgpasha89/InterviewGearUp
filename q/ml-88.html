How does the Vision Transformer (ViT) apply standard Transformer encoders to non-overlapping image patches?

ML / AI engineer · Gear 3 (Senior) · Vision · Difficulty: hard · AI-drafted, not yet reviewed by a person

In 30 seconds

ViT splits an image into fixed non-overlapping patches, flattens and linearly projects each into a token embedding, adds position embeddings and a learnable class token, and feeds the sequence to a standard Transformer encoder. Self-attention then relates patches globally, and the class token output goes to a classifier head. It needs large-scale pretraining because it has weaker inductive biases than CNNs.

Explained in depth

Pipeline

Given an image of size H × W × C (for example 224 × 224 × 3) and patch size P (16):

  1. Patchify: split into N = (H/P)·(W/P) non-overlapping patches (14 × 14 = 196). Each patch is P × P × C = 768 raw values.
  2. Patch embedding: flatten each patch and apply a learned linear projection to dimension D (768 for ViT-Base). Equivalent to a convolution with kernel and stride P.
  3. Prepend a learnable [CLS] token (a vector like BERT's class token) so the sequence has N + 1 tokens.
  4. Add position embeddings (learned 1D, one per position; 2D or sinusoidal variants exist) because attention itself is permutation invariant; this tells the model where each patch came from. At new resolutions the position embeddings are interpolated.
  5. Transformer encoder of L layers (12 for Base): each layer is LayerNorm → multi-head self-attention → residual → LayerNorm → MLP (GELU) → residual. Attention lets every patch attend to every other patch from the first layer, giving a global receptive field immediately.
  6. Classification head: take the final [CLS] embedding (or mean-pool patch tokens) → MLP head → logits.
import torch, torch.nn as nn
class PatchEmbed(nn.Module):
    def __init__(self, img=224, p=16, c=3, d=768):
        super().__init__(); self.proj = nn.Conv2d(c, d, kernel_size=p, stride=p); self.n = (img // p) ** 2
    def forward(self, x):                                   # (B, C, H, W)
        return self.proj(x).flatten(2).transpose(1, 2)      # (B, N, D)
class ViT(nn.Module):
    def __init__(self, d=768, depth=12, heads=12, classes=1000):
        super().__init__()
        self.embed = PatchEmbed(d=d); self.cls = nn.Parameter(torch.zeros(1, 1, d))
        self.pos = nn.Parameter(torch.zeros(1, self.embed.n + 1, d))
        layer = nn.TransformerEncoderLayer(d, heads, 4 * d, activation="gelu", batch_first=True, norm_first=True)
        self.encoder = nn.TransformerEncoder(layer, depth); self.norm = nn.LayerNorm(d); self.head = nn.Linear(d, classes)
    def forward(self, x):
        t = self.embed(x); t = torch.cat([self.cls.expand(len(t), -1, -1), t], 1) + self.pos
        return self.head(self.norm(self.encoder(t))[:, 0])

Cost and design choices

  • Self-attention is O(N²·D) in the number of patches. Smaller patches (8 instead of 16) give a finer representation but 4x more tokens (about 16x attention cost); larger images likewise. Variants: ViT-B/16, ViT-L/16, ViT-H/14.
  • Model sizes: Base 86M, Large 307M, Huge 632M parameters.

Inductive bias and data hunger

CNNs hardcode locality and translation equivariance, which helps with small data. ViT has little image-specific bias: it must learn these from data. Consequently ViT trained only on ImageNet-1k underperforms CNNs, but pretrained on large datasets (JFT-300M, ImageNet-21k, LAION) it matches or surpasses them and scales better with compute. Solutions for smaller data:

  • DeiT: strong augmentation, regularisation, and distillation token from a CNN teacher.
  • Self-supervised pretraining: MAE (masked autoencoders: mask 75 percent of patches and reconstruct), DINO/DINOv2, BEiT, CLIP (contrastive image-text).
  • Hierarchical and local-attention designs: Swin Transformer (shifted windows, patch merging for multi-scale features, linear complexity), PVT, MViT, ConvNeXt-style hybrids, CoAtNet; important for dense tasks like detection and segmentation.

Applications

Image classification, detection (DETR, ViTDet), segmentation (SegFormer, Mask2Former, SAM), vision-language models (CLIP, LLaVA, multimodal LLMs use ViT encoders), video (ViViT, VideoMAE), medical imaging, remote sensing.

Practical notes

Fine-tune pretrained checkpoints (timm, Hugging Face) at higher resolution with interpolated position embeddings, use mixed precision and FlashAttention, layer-wise learning-rate decay, and strong augmentation (RandAugment, Mixup, CutMix).

Pitfalls

Training from scratch on small datasets, mismatched normalisation and resolution at inference, ignoring quadratic cost at high resolution, and treating the [CLS] token as the only usable feature (patch tokens carry dense information).
