Design an image carousel component supporting touch gestures, infinite loops, and accessibility.

Frontend engineer · Gear 2 (Mid-level) · Architecture · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

A carousel needs a track of slides translated with transform, pointer events for drag and swipe with velocity and snap, scroll-snap as a simpler foundation, cloned edge slides or modular indexing for infinite looping, and full accessibility: labelled region, controls, pause for autoplay, keyboard support and reduced motion respect.

Explained in depth

Option 1: CSS scroll-snap (preferred baseline)

.track { display: flex; overflow-x: auto; scroll-snap-type: x mandatory; scroll-behavior: smooth; overscroll-behavior-x: contain; }
.slide { flex: 0 0 100%; scroll-snap-align: center; }

The browser provides native touch physics, momentum, keyboard scrolling and accessibility. Use IntersectionObserver to track the active slide and drive indicators; scrollTo for buttons. New CSS ::scroll-button() and ::scroll-marker features can generate controls natively.

Option 2: custom transform track

Use pointer events (works for mouse, touch and pen) with touch-action: pan-y so vertical scrolling still works:

let startX, dx, startT;
track.addEventListener('pointerdown', (e) => { startX = e.clientX; startT = e.timeStamp; track.setPointerCapture(e.pointerId); });
track.addEventListener('pointermove', (e) => { if (startX == null) return; dx = e.clientX - startX; track.style.transform = `translateX(${base + dx}px)`; });
track.addEventListener('pointerup', (e) => {
  const v = dx / (e.timeStamp - startT);                     // px per ms
  if (Math.abs(dx) > width / 4 || Math.abs(v) > 0.5) go(dx < 0 ? +1 : -1); else go(0);
  startX = null; dx = 0;
});

Disable transitions while dragging, animate to the snap point afterwards using transform (GPU friendly), and add rubber-band resistance at ends when not looping.

Infinite loop

  • Clone approach: append clones of the first slides and prepend clones of the last; after the transition ends on a clone, jump (no transition) to the real slide.
  • Modular index: keep a window of slides and rotate DOM order or compute position as (i mod n), repositioning off-screen items. Avoid duplicating focusable content (hide clones with aria-hidden and inert).

Accessibility

  • Container role="region" with aria-roledescription="carousel" and a label; each slide role="group" aria-roledescription="slide" labelled "2 of 5".
  • Previous and next buttons with accessible names, visible focus, large touch targets; pagination dots as real buttons (aria-current).
  • Autoplay: avoid by default; if used, provide a visible pause button, stop on hover and focus, stop permanently once the user interacts, and honour prefers-reduced-motion. WCAG 2.2.2 requires pause for moving content over 5 seconds.
  • Do not announce every auto-change; use aria-live="off" while rotating and "polite" when the user navigates. Hide offscreen slides from the tab order (inert).
  • Keyboard: Arrow keys, Home and End when the carousel has focus.

Performance and UX

Lazy-load offscreen images (loading="lazy", decoding="async"), reserve aspect ratio to avoid layout shift, preload the next slide, and pause video. Avoid carousels for critical content because engagement on later slides is low.
