How do you find the Longest Common Subsequence (LCS) of two strings using dynamic programming?

Software engineer (core) · Gear 3 (Senior) · Dynamic programming · Difficulty: medium · AI-drafted, not yet reviewed by a person

In 30 seconds

LCS finds the longest sequence of characters that appear in both strings in the same order, not necessarily contiguous. Define dp[i][j] as the LCS length of the first i and j characters: add one on a match, otherwise take the larger of dropping a character from either string. It runs in O(MN) time, and the table can be walked back to recover the sequence.

Explained in depth

Recurrence

  • If a[i-1] == b[j-1]: dp[i][j] = dp[i-1][j-1] + 1
  • Otherwise: dp[i][j] = max(dp[i-1][j], dp[i][j-1])
  • Base: dp[0][*] = dp[*][0] = 0
def lcs(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]

# lcs('ABCBDAB', 'BDCABA') -> 4

Complexity

O(M*N) time and O(M*N) space. Since each row depends only on the previous row, you can keep two rows and use O(min(M, N)) space (you then lose the ability to reconstruct the sequence easily).

Reconstructing the answer

Start at dp[m][n] and walk back: on a character match, take it and go diagonally; otherwise move toward the neighbour with the larger value. Reverse the collected characters.

Related

Edit distance, shortest common supersequence, longest common substring (which needs contiguity, so resets to zero on a mismatch) and the diff utilities in version control.

Likely follow-ups
